# BladeVMS · 旋转叶片测振与损伤检测系统

以 `../原型/旋转叶片测振系统-双通道原型.dc.html` 和 `../原型/原型-截图/` 的 18 张截图为依据。

本项目包含 Next.js Web 管理端与业务 API、Electron Windows 现场工作台、共享 React UI。**Python 算法与采集设备未接入**；业务数据真实存入独立 MySQL 库，原始波形与截取保留已保存采样值，算法图表与算法结果明确标注为演示。不要将演示数值用于工程判断。

交付范围、需求覆盖与已知验证限制见 [DELIVERY.md](DELIVERY.md)。Windows 包已交叉构建；Windows 实机与最新宽报告的浏览器打印仍需目标环境验收。

## 快速启动

建议 Node.js 22 LTS（至少 22.12）或更新的受支持 LTS、npm 10+。在 `playground` 目录执行：

```bash
npm ci
npm run db:setup
npm run db:migrate
npm run dev
```

- Web 管理端：http://127.0.0.1:3210
- 桌面布局预览：http://127.0.0.1:3210/desktop
- 默认管理员账号：`admin`。随机初始密码保存在 `apps/web/.env.local` 的 `BOOTSTRAP_PASSWORD` 中；不会输出到日志或打包进桌面应用。
- 演示角色：`zhang`（分析员）、`li`（操作员）、`guest`（访客），初始密码相同。请在系统管理中修改默认密码后再用于真实团队。
- `db:setup` 在环境文件存在时直接退出，不覆盖现有密码。`db:migrate` 只初始化本项目表，不清空业务数据。

## 桌面开发与打包

另开终端：

```bash
# 本地浏览器预览，端口 5210，通过代理调用 3210 的 API
npm run dev:desktop

# 打开 Electron 热更新界面（需上述两个开发服务已启动）
BLADE_DEV_URL=http://127.0.0.1:5210 npm run desktop

# 或加载本地打包资源，不依赖 Vite 开发服务
npm run build -w @blade/desktop
npm run desktop

# Windows x64 压缩发行包
npm run package:windows
```

输出：`apps/desktop/release/BladeVMS-1.0.0-win.zip`。解压完整目录后运行 `BladeVMS.exe`，不要单独移动 EXE。当前包未做商业代码签名；受管 Windows 环境应由 IT 审核并配置签名，勿通过关闭系统防护来部署。

Windows 与数据库服务器不在同一台机器时，在登录页“配置服务器地址”中填入服务器的 HTTPS / 局域网地址，不能沿用 `127.0.0.1`。桌面端通过受限原生桥接调用 API，不直接连接数据库。

服务不可用时可进入“离线演示工作区”：本机任务、导入波形和演示分析存入用户目录的 `blade-offline.json`，原子替换写入；不会自动上传或覆盖服务器记录。它是本机工作区，不是多用户权限隔离的数据库。原始波形与分析数值支持 CSV/TXT/XLSX/MAT/JSON 离线导出；通用业务列表离线支持 CSV/TXT/JSON，Web 管理功能需在线服务。

### 显式回传本机任务

桌面应用右上角“回传本机任务”在在线和离线模式均可使用。核对目标服务器，在弹窗登录接收账号，勾选本机任务和确认项，再点击“确认回传”。在弹窗登录不会离开本机工作区；退出工作台也会清除回传登录状态。

- 一份任务连同关联分析作为一个事务上传；不上传用户设置或令牌，不删除本机任务，不覆盖服务器已有记录。
- 同一工作区/任务修订向同一用户及课题组重复上传只保留一组服务器记录。编辑本机任务或分析后形成新修订，下次回传另建记录。
- 失败任务保持选中，可再次确认后重试。停止操作只停止后续任务，正在进行的请求仍等待服务器确认。
- 本机回执按服务器、用户和课题组区分；它不是服务器记录仍存在的保证，重试时由服务器重新核验。服务器记录已删除时明确报冲突，不静默复活。
- 每批最多 50 项任务；每项最多 50 份关联分析、2 MB。现有任务采样数组仍受 20000 点限制，不是高频数据传输方案。
- 旧版工作区首次打开时持久化稳定客户端标识。损坏或结构无效的本机文件会报错退出，不用演示数据覆盖原文件；请检查权限或从有效备份恢复。

### 健康监测与追溯

健康监测和模态页面均有“基线管理”。管理员/分析员可手工登记、复制为当前课题组副本、编辑、启停或确认删除；其他角色可查看与选择适用基线。空组也有维护入口。这里不从波形生成或训练基线，也不认证为真实正常态。

RMS、主频和一阶模态频率可分别登记，留空不补默认值；仅有一阶频率的旧记录仍可用于模态基准，但不会显示虚构的健康面板。健康度/置信度字段明确只用于原型演示显示，来源区分手工登记、演示样例与未注明的旧记录。停用后不再用于新分析，当前选择失效时提示重新选择，不静默替换为另一基线。

修改和删除均检查读取时的 `revision`；并发或过期编辑提示冲突并保留表单，返回列表刷新后再编辑。不变内容不增长版本，真正编辑生成新 `version`。删除需要勾选确认，只删除登记，不删除已保存模态、趋势、波形或报告快照；如需恢复登记，可从有效业务备份恢复。管理员编辑其他课题组记录时仍保留原归属，副本则明确保存到本人组。

健康监测配置按所选基线所属课题组读取。所有已登录角色可读取必要阈值，只有管理员可修改；非管理员仍不能读取系统设置和模型配置。缺少/无效配置显示“未判定”，缺少基线不显示虚构健康度。旧配置的注意比例暂按预警比例的 75% 兼容并明确提示，管理员确认保存后转为完整配置。指标与趋势仍是标明的原型演示样例，不由任务或真实算法计算。复核身份/时间由服务端生成、历史追加保留；溯源与报告使用明确选中的关联任务。

预警面板现有 RMS、主频偏移、频带能量、峰值、峰峰值、主频幅值六项，显示单位、当前值、阈值与分级。后三项阈值可留空或清空，旧配置不会自动补值。覆盖数明确显示“3/6”等；缺失项不算正常，不能凭部分正常指标宣称整体正常。频带能量为任意单位 a.u. 的演示值。演示检测保存完整严重程度、定位、判据、结论及六指标/阈值快照，报告采用中文字段。

“趋势跟踪与归档”可设置展示起日，保存固定 30 日演示趋势、当时任务元信息/基线/阈值，以及源任务已有的原始波形。任务无采样点时不补造波形。相同账号、来源修订、基线/阈值修订与展示日期的重复提交使用同一记录；来源或配置已变化则提示刷新。趋势日期不代表真实长期测量，每天趋势点与任务采样点不存在真实时间映射。

新趋势包含幅值/RMS、频率、模态频率、频带能量、峰值、峰峰值、主频幅值、阻尼比八条百分比变化率曲线，按主要趋势/幅值指标/模态参数/全部指标分组展示；分组只改变图表，不缩减导出。零线不是实测基线，样例变化率不对应上方绝对值。旧三曲线归档保留原列与标记能力，不给缺失曲线补值；样例版本纳入新归档去重标识，历史记录不被新版覆盖。

从“趋势记录”打开历史，或勾选“全部可见归档”检索其他任务；原任务/基线删除后，分析员和访客仍可读取所属组历史，操作员仍要求关联其本人且尚存在的任务。归档可切换趋势与原波形、变速回放、点击标记定位、导出 CSV/TXT/XLSX/MAT/JSON，并查看完整元信息。报告增加“健康趋势与标记”章节，保存时冻结归档及当时标记。

管理员/分析员可给趋势或波形添加“待复核 / 异常 / 已确认”人工标记，位置为从 0 开始的半开索引区间 `[起点,终点)`。标记不修改数值、不是自动检测或异常剔除；撤回需填写原因，初始记录、身份、时间与撤回历史保留。每份归档最多 200 条（含撤回），不可经通用记录接口改写或删除。告警“人工复核标记”与信号标记分开留痕。

### 旋转测振与有效段

选择有原始波形的任务，确认手动转速、叶片数及时间范围，点击“生成分段”。可按恒定转速推算叶片通过周期边界，或选择一个手动时间范围；每段可标注类型、质量和备注。勾选项决定保存与导出，剔除异常段只取消人工标为异常的保留项，不删除源数据。原始图高亮所选区间，多段对比最多绘制前 6 段，按各段起点对齐，不代表相位同步。

“截取并保存”生成一份分段分析，不创建拼接任务、不替换原任务。CSV/TXT/XLSX/MAT/JSON 均包含分段编号、源采样索引、原任务时间与原始幅值；全部段标注、排除区间和原因进入元信息。非连续段保留时间间隔，不伪装成连续等间隔信号。源任务或参数变化后须重新生成；在线服务和离线主进程独立校验版本与边界，不接受客户端伪造的截取数值。已保存历史保持原输入元信息和采样值。

一次最多 200 段，沿用原始任务 20000 点上限，时间上限按实际点数/采样率计算。未完整的尾段明确标记，所有质量初始为“未评价”。自动稳定段、键相、信号估计、转速同步重采样和真实阶次算法均未接入。阶次导出对应原型四根柱高，只随手动参数换算频率关系，不声称由所选任务计算。

### 文件边界

模态结果分为模态参数、多测点频率曲线、各阶振型节点、基准频率对比四类，当前页面和历史窗口均可逐类选择 CSV/TXT/XLSX/MAT/JSON 导出。P1/P2/P3 仅为原型演示位置，勾选决定曲线列及振型节点；不代表所选任务有三通道同步数据。方法、阻尼和阶次配置真实保存，但不会据此执行识别算法。

正常态基准可选明确标记的原型样例，或同课题组/同对象已有基线。当前基线仅存一阶模态频率，二、三阶显示无法比较，不补造数值。当前频率与参数表统一；相对变化率保存 8 位小数、界面显示 2 位。二维振型灰线是未变形参考，不是已测正常态振型；导出固定节点数据，不导出播放相位。历史结果冻结任务元信息、所选测点及基准；任务或基准修改后，旧界面保存被拒绝，历史导出仍使用原值。

- JSON 导入：任务对象或任务数组，最多 50 条；单文件不超过 1.5MB。先逐项预检，再确认导入有效项；必填字段缺失会显示原因，不再套用演示任务值。
- CSV 波形导入：一列幅值或 `时间,幅值`，支持表头、引号、BOM 和本系统的带元信息原始波形 CSV；最多 20000 点。确认采样率和单位后导入，时间列须从 0 开始并匹配采样率。不静默截断数据或丢弃时间列。
- CSV/TXT/XLSX/JSON：业务记录导出。MAT：已保存波形的 MATLAB level-4 文件，`wave_N` 两列为时间（秒）/幅值，另有 `sample_rate_N`、`is_demo_N`、`metadata_json_utf8_N`。最后一项为完整元信息 JSON 的 UTF-8 数值字节，可还原中文、时间、通道和工况。无波形时明确报错。
- 新增数值导出：历史任务的“导出原始波形”、信号页“导出当前标签”、分析记录“结果 / 导出”和批处理结果“导出数值结果”，均支持 CSV/TXT/Excel/MAT/JSON。当前标签导出对应图中所有行/系列，热图使用实际轴值；未执行真实算法。任务下拉还保留“任务记录 JSON”，用于原有任务导入。
- 数值 CSV/TXT 前两条记录为说明和完整元信息，第 3 条为表头；Excel 使用数据/元信息两个页；MAT 使用 `values` 和 UTF-8 元信息保存数值及文本列。具体读取协议见 `API.md`。不要把数值数据集 JSON 当作任务记录 JSON 导入。
- 数值矩阵最多 20000 行、32 列，不静默截断或填补缺值。旧分析若只有说明则不能导出数值，可导出原记录 JSON。原生数据保存单文件最多 16 MB，逐次弹出保存窗口，可取消；失败不提示成功。
- “完整元信息 / 通道”支持测试时间（录入本机时区、保存为 ISO UTC）、环境、故障类型、备注与最多 16 个通道描述。通道描述不等于多通道波形；当前导入是单列幅值，不执行单位换算。`raw_preserved` 根据已保存采样点自动计算，不接受客户端伪造。
- 历史回放按原采样率推进，支持 0.5×/1×/2×、暂停、拖动采样位置和恢复完整波形。回放窗口不改变原数据；没有保存波形的任务不能回放。
- 演示快照固定保存 400 点，时长按 `400 / 采样率` 计算，预览时间轴使用相同采样率；不再把该短缓冲区标成固定 2 秒或真实 0.5～3 秒采集窗口。真正的定时采集快照由未来设备接口提供。
- 报告新建时冻结任务/分析。加载历史后，编辑标题、结论或章节不更新旧数据；要引用最新任务和分析，请明确点击“用当前数据新建”。历史 Word 导出只读，访客也可使用。Word/PDF 包含已存波形、频谱等图表、可分页参数和数值预览；PDF 图表采用 SVG。每张数值表注明预览范围，完整精度数据在侧栏“导出报告数据”选择原始波形或分析/子结果后下载，使用同一报告快照，不读取后来修改或删除的源记录。
- 原始高频数据流、真正的滤波/FFT/模态/损伤计算、真实设备连接、模型显著区由未来接口提供；当前不宣称已经实现。

### 可恢复的任务文件导入

历史列表“导入 JSON / CSV”打开预检窗口，展示每条任务、波形点数、采样率、单位和错误/警告。点击“确认导入有效项”后逐项保存；“停止后续导入”等待当前请求确认后停止，不撤销成功项。重新打开或重启应用，从“导入记录”选择批次并继续。

每条成功项只创建一次；响应丢失时显示“状态待核验”，再次继续会读取已保存状态。任务与进度一起保存，不覆盖文件中同 ID 的原任务。修改任务后重试也不会覆盖修改；已删除的导入任务不被静默重建。校验失败项可“导出未导入项 JSON”，修正后另建批次，导出文件不夹带已成功项。

重新选择文件并确认会新建批次，可能有意导入另一份副本；对已有批次的重试必须走“继续导入”。在线导入业务接口限本人查看/执行，管理员也不接管他人的批次；管理员按权限创建的本课题组完整业务备份仍包含导入输入和进度。离线工作区沿用本机单用户模型。CSV 的元信息可在确认前调整，波形时长以点数/采样率保存；通道描述不意味着多通道采样。

### 历史任务批处理

在历史列表勾选任务后点“批量处理”，配置降噪、截取、FFT、特征提取步骤，创建批次，再点“继续批次”。暂停会等待当前请求确认后停止后续步骤；重新打开或重启客户端后，从“批次记录”继续。

批次保存创建时的输入快照，不覆盖原任务。成功步骤不重复生成结果；失败项显示原因，其他任务仍可继续。要更改配置或使用更新后的输入，可“复制配置新建批次”。结果可查看图表/前 100 行，并以 CSV/TXT/Excel/MAT/JSON 导出全部数值、参数、输入元信息及采样范围；原记录 JSON 另有入口。批处理结果也可进入报告；报告使用摘要与结果 ID，避免将整列采样塞入一个单元格。

降噪、FFT 和特征没有调用真实算法：降噪预览保留输入，频谱和特征为固定演示值。截取使用保存样本的 `[起点,终点)` 区间，不改变原始幅值。输入为空、越界或无访问权限时明确失败。每批最多 50 个任务、输入快照最多 8 MB，当前不是大规模后台计算服务。

## 数据库隔离

复用现有容器 `starlight-mysql`（宿主端口 3306），仅新增：

- 数据库：`blade_vms_playground`
- 账号：`blade_vms_app`，权限限定在该库
- 表：见 `scripts/migrate.mjs`

不创建/重启/更改其他容器，不改现有数据库账号和服务配置。服务启动及迁移均校验库名。创建前后的数据库及容器记录位于 `artifacts/`。请勿把 `.env.local` 或 Electron 用户配置发布到代码仓库。

业务备份仅覆盖某一课题组的业务记录，不是 MySQL 物理灾备。恢复需输入“恢复业务数据”，在事务中恢复备份所属课题组，不恢复账号/会话/审计，也不触碰其他数据库。

## 权限与接口

管理员管理全部课题组；其他角色限制在所属课题组。操作员只能管理本人任务、读取/导出本人任务的关联结果，并保存基础分析；不能执行模态/损伤分析或编写报告。分析员可保存分析/报告和复核告警，访客只读。服务端负责授权，不依赖前端按钮隐藏；具体资源限制见 [API.md](API.md)。

登录/退出及桌面服务器、离线工作区切换会清理前一工作区的任务选择和跨页上下文。底栏只显示当前账号可访问列表内的任务；没有可访问任务时显示“任务：无”，不沿用前一账号的名称或采样参数。

接口入口：`/api/v1`。详细请求与错误说明见 [API.md](API.md)。当前功能清单和验证进度见 [IMPLEMENTATION.md](IMPLEMENTATION.md)。

## 信号输入与对比验收

信号页现可选择整条任务或已保存保留段。时域保留原幅值、原单位与原任务时间；多测点支持原任务时间/各自起点归零两种观察方式，不重采样、不补点、不声称同步。对比限同组同对象同单位、2～6 个输入且合计不超过 20000 点，可先截取短段。没有波形或输入已删除时明确不可用，不静默回退整条任务。

新分析冻结来源修订并禁止改写；跨任务所有者的对比及包含它的报告不向首任务操作员扩大可见范围。原型算法标签仍是演示结果。输入、曲线、保存结果、CSV/TXT/XLSX/MAT/JSON 导出使用同一数据契约。
