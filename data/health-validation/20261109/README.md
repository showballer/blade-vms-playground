# 第二组叶片 2：局部响应缺陷注入测试

本数据是**明确标识的测试副本**，用于验证健康监测中的局部异常预警；不是现场结构损伤证据。原始 Git 采集包保持不变，其他叶片也未据此被判为健康。

- 批次：武川风场-R024-1101-第二组。
- 叶片 2，P3，0°、90°、180°、270°四个独立有效连续段。
- `paired-waveforms.npz`：每个角度的完整采样时间 `time_i`、原样对照 `reference_i`、注入测试波形 `test_i`，速度单位 m/s，时间单位 s。数组编号对应 `result.json` 的 `items` 顺序。
- `result.json`：来源哈希、原样索引范围、注入参数、滑动窗口特征、异常区间以及抽稀展示曲线；不包含本机账号、数据库对象 ID 或绝对代码路径。
- `manifest.json`：文件字节数和 SHA-256。

算法对单点连续波形的中部加入平滑局部残差增益和短时振荡；检测器比较配对波形的滑窗 RMS、峰峰值和超限持续性，独立于注入位置参数。1.8 倍双指标连续至少 3 窗触发测试预警，持续区间 RMS 达到 3 倍时标记高等级响应异常。阈值仅用于工程测试，未做现场损伤标定。原样是注入试验对照，不是经过验证的健康基线。

仓库根目录验证：

```sh
PYTHONPATH=services/acquisition python scripts/verify-health-validation.py
```

需要 NumPy；可使用项目分析服务的 Python 虚拟环境。部署端对象 ID 与本机不同，不能直接导入本机数据库快照；恢复关联及页面测试记录的方法见 `docs/health-response-revision-20261109.md`。
