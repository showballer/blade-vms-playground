这是 2026-11-05 本机数据快照，可在 Mac 和 Windows 新版客户端中导入。

每个任务按叶片分成 3 个 ZIP，便于通过 Git 下载。**它们不是 3 个任务，请一次多选同一文件夹里的 3 个 ZIP。** 无需解压，也不需要连接采集设备。

## 客户端操作

1. 更新代码并启动桌面客户端，登录账号。
2. 打开 **记录分析 → 叶片响应分析 → 导入户外分段**。
3. 点击 **选择 ZIP（可多选）**，选择一个任务文件夹内的 `叶片1.zip`、`叶片2.zip`、`叶片3.zip`。
4. 将“任务名称”填为上表中的完整任务文件夹名；核对风场、风机和 P1～P5 半径。预览应为 **60 条记录、3 个叶片、5 个测点**。
5. 点击 **建立户外任务**。在“叶片”下拉框选择叶片 1、2 或 3，再点击 **开始分析**。
6. 用相同步骤导入另一个任务。不要把两个文件夹的 ZIP 混选，也不要逐个 ZIP 建立任务。
