### HTTP 统一账号与离线密码行为

- 1.4.0 允许绑定标准 HTTP 或 HTTPS 源地址；发布版默认地址为 `http://115.190.201.41:3000`。账号请求不跟随重定向，仍拒绝带路径、查询、片段或嵌入凭据的服务器地址。远程 HTTP 的账号、密码及会话信息明文传输，绑定界面和账号卡片显示此提醒。
- 新安装仍先使用独立的本机初始账号，首次登录须修改初始密码；覆盖升级保留既有本机密码与采集记录。进入“设备与服务 → 账号与密码 → 绑定 Web 账号”，同时验证当前本机密码和 Web 账号密码。成功后由绑定的 Web 账号接管桌面登录，旧本机密码不再用于登录；采集记录不会因绑定自动上传。
- 每次登录先尝试 Web 验证。成功绑定、成功联网登录或在客户端成功修改统一密码，均会刷新该机器的离线密码缓存，并从该次成功验证起重新计算 30 天离线登录有效期。离线登录本身不会延长有效期。
- Web 修改或重置密码不会主动推送到已登录或断网的桌面。应停止并保存采集，退出账号，再联网用新密码登录一次；该次成功登录后，当前机器才改用新密码进行离线验证。
- 尚未完成上述联网验证时，断网只能使用此前成功验证的缓存密码，且须仍处于 30 天有效期内、离线缓存未被停用；新 Web 密码不能直接用于这台机器的离线登录。若旧密码联网被服务器拒绝（401/403），旧离线缓存会被持久停用，必须用有效密码联网恢复。
- 只有连接不可达、断网或连接超时等传输失败才允许离线验证。服务返回错误、异常响应和证书错误不视为离线回退条件。Web 改密不会强制中断客户端已经运行的采集会话。
