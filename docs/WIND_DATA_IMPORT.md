# 风场工况导入与预览

入口：Web → 风场数据集。先选择风场，文件中的风机名称须已登记在该风场下。

## 标准 CSV

首行为以下七列，数据按分钟提供；同一格式可包含多个风机。

| 列名 | 系统字段 | 默认单位 / 含义 |
| --- | --- | --- |
| 名称 | turbineCode | 风机编号，保留前导零及 `#`，例如 `006#` |
| 时间 | time | `YYYY-MM-DD HH:mm:ss`，默认北京时间 UTC+8 |
| 风速 | windSpeed | m/s |
| 发电机有功功率 | powerKw | kW，允许负值 |
| 主轴转速 | rpm | rpm |
| 舱外温度 | temperatureC | ℃，允许负值 |
| 风向 | windDirection | °，保留 −360～360 的原值 |

识别完整七列后自动填入列映射和上述单位，点击“确认单位与时区并导入”才会保存。单位可在导入前修改；原始时间已带时区时保留其含义，存储统一为 UTC。UTF-8 和 GB18030 均支持。

风向基准尚未确认，因此保存 `windDirectionReference: unspecified`，不做取模、不转换为正北方位角，也不用于方向诊断。空值保留为缺失，数值 0 保留为 0。

原先“风机、轮毂转速、发电机侧有功功率、外界温度”等列名仍可识别；各指标分文件导出时只合并同风机、同时间的数据，不填补缺失指标。未识别为标准七列的文件仍须选择单位。同风场、风机、时间和指标重复时拒绝导入，不覆盖旧值。

## 大数据预览与删除

- 每份最多 16 MB / 25 万行，一次最多 8 份，合并后最多 25 万个风机时间点。
- 已保存列表仅加载摘要。点击“预览”后默认每页 50 条，可选 20 / 50 / 100 条；数据库仅向服务端返回本页记录，浏览器不接收全量数据。
- 预览支持首页、上一页、下一页、末页；风速与转速共同覆盖时间晚于数据集起始时间时，可直接跳到共同覆盖开始处。表格时间固定显示北京时间，缺失值显示 `—`。
- 分页接口：`GET /api/v1/wind-datasets/:id/rows?offset=0&limit=50`。`limit` 为 1～100；`at=<UTC ISO 时间>` 可替代 offset，从不早于该时间的第一行开始。
- 删除接口：`DELETE /api/v1/wind-datasets/:id`，需要分析员或管理员权限。页面确认数据集名称和记录数后删除，记录审计；不删除风机、波形或历史分析结果，新分析不再使用已删除工况。
- 读取与删除均按当前租户及记录类型隔离。错误状态支持重试，读取失败不会用旧数据冒充成功。
