# 风机叶片定点测振实施与验收方案

版本：2026-10-19 方案及单点首版实现记录。适用项目：BladeVMS 桌面采集与 Web 分析。

首个交付目标是在旋转状态下可靠识别一片叶片上的一个指定材料测点，获得可说明方向、频带、幅值定义和质量的振动结果；单点通过后，再扩展同一叶片从叶根到叶尖的多个测点。四个钟点方向用于初期标定和驻留试验，不作为最终数据模型。

方案确认后，已按用户要求实现单叶片单测点的静止准备、人工过点同步、一次短弧预测运动和桌面参数页面。实际操作、实现边界与本地验证记录见 [单点跟随使用说明](SINGLE_POINT_FOLLOWING.md)。本轮未操作转盘或激光，未做新的实机验收，未提交推送或发布客户端、服务器。多点仍属于后续阶段。

## 1 已确认条件与首版范围

| 条件 | 当前依据 | 实施含义 |
|---|---|---|
| 转盘作用 | 用户确认两轴转盘调整激光测振仪的瞄准方向 | 转盘角度和转速不能当成风机叶轮的角度和转速 |
| 叶轮运动 | 独立于转盘；模型约 5 秒一圈 | 规划标称值为 12 rpm、0.2 Hz、72°/秒；不是已测得的实时转速 |
| 首轮测试条件 | 用户确认可以停转，将目标测点摆到6点方向；目前没有接入电脑的转速或相位信号 | 可以静止绑定材料点；电机启动和人工点击不能直接当作精确相位基准 |
| 叶片与现有位置 | 照片为三叶片模型，已有 6、9、12、3 点观测方向 | A、B、C 的物理身份仍需现场绑定；四方位各自保存两轴标定值 |
| 仪器与连接 | 本机读取过 VFX-F-110 配置，使用 Mac 原生兼容 SDK；转盘 USB 与以太网共用一个扩展坞 | 首版继续适配现有接法，先测稳定性，不把换扩展坞当作既定前提 |
| 参考计算方案 | 用户提供理想正对模型及角度表、时序草案 | 作为几何和流程输入，不把其中 100 m、80 m、250 m、40°、30°/秒、1 秒停稳等作为本模型实测参数 |
| 远端 | 115 已部署转盘记录与 RSSI 兼容更新 | 部署检查通过；同一次真实联合任务的自动上传、实时查看和归档仍待验收 |

首版以“一片叶片、一个材料测点、一个明确的振动指标”为范围。先完成静止测点校准、旋转身份识别和单点测量验证，再扩大轨迹范围与测点数量。户外远距离、偏航变桨、全叶片缺陷识别属于后续扩展，不以模型连通代替户外验收。

## 2 测量对象与结果定义

### 2.1 测点身份

每个材料测点由“风机 ID、叶片 ID、测点 ID、沿叶片位置、弦向位置或可辨认标记、几何标定版本”定义。仅有“距轮毂的半径”不能唯一确定叶片表面上的一个材料点。

例如 A/P2 表示 A 叶片上的第二个材料测点。它旋转到 6 点或 12 点方向时，测点身份不变。观测方位、圈号、时间、转盘角度是该测点某次测量的附加信息。

沿叶片位置允许输入距叶根的实际距离，或叶长比例 η；二者自动换算。若叶长从法兰/叶根开始计量，圆周半径应加入轮毂到叶根的偏置，不能直接把叶长比例当成距旋转中心的半径。首版可用现场材料标记帮助复现弦向位置；多点数量不固定为 3 或 5。

### 2.2 三种测量方式

| 方式 | 光斑行为 | 能交付的结果 | 边界 |
|---|---|---|---|
| 手动定点与静止校准 | 叶轮停转，光斑瞄准材料标记 | 点位校准、通道量纲、静止工况下的振动验证 | 不能证明旋转时同点跟踪成立 |
| 相位同步驻留 | 提前移动到空间方位，停稳后等待指定叶片 | 带叶片身份和相位的过叶短段、经过区域的振动信息 | 光斑会扫过不同弦向材料位置；不能把整个短段称为同一材料点的连续历史 |
| 同点跟踪 | 根据相位连续更新两轴轨迹，让光斑保持在同一材料测点区域 | 指定可见轨迹内的同点连续振动；通过后扩展整圈 | 需要验证连续轨迹能力、命中误差、有效时长和运动附加信号 |

“跨圈等待”是调度策略，既不是连续跟踪，也不自动获得连续数据。只有周期稳定性和重构方法经过验证时，才允许将跨圈相位样本用于周期分量重构；不能把间隙去掉后直接当成连续波形做 FFT。

### 2.3 振幅指标

首版先报告实际通道的视线方向振动速度，例如 mm/s RMS、峰值和峰峰值；需要位移振幅时，报告指定频带内的动态位移，例如 μm RMS 或峰值，并保存积分、滤波和方向换算配置。不能将 RSSI 回波强度当振幅，也不能把积分漂移当成叶片静态挠度。

对单一谐波，速度峰值与位移峰值满足 A位移 = A速度 / (2πf)。宽带信号须按验证过的频域或时域处理链计算，不能用一个“主频”除整个速度 RMS。单束激光测得视线方向分量，未完成方向标定时不能显示为完整三维振幅。[Polytec 测振原理](https://www.polytec.com/en/vibrometry/know-how/laser-doppler-vibrometry)

测量配置须明确目标频带、幅值口径、最小关注幅值、需要的频率分辨率和参考量。缺陷判断在测量链验收之后开展：先建立相同测点、相近转速与工况的健康基线，再评价变化；振幅增加本身不等于已有缺陷。

## 4 计算方案的采用与修订

### 4.1 保留理想几何并增加现场标定

保留参考文档的理想正对模型。用 r 表示距旋转中心的半径，x 表示侧向位置，y 表示高度，D 表示激光器到叶轮平面的正向距离：

- x = s·r·sinφ，y = H + r·cosφ。
- 水平角 ψ = atan2(x, D)。
- 世界仰角 θ = atan2(y−h0, √(D²+x²))。
- 参考文档约定 φ=0°为最高点、180°为最低点；系统保存旋向 s，显示坐标约定，不能同时重复翻转 φ 和 s。

这组公式对应“正前方、允许仪器与轮毂存在高度差”的布设。H≠h0 时不能称光轴与转子轴线重合。公式输出还须经过安装姿态、零位、轴方向及轴间几何标定，才能得到机械角度。

模型现场先量取轮毂中心、叶根起点、叶长、设备相对位置及材料标记；不使用户外算例尺寸。对于侧偏、倾斜等情况，采用三维坐标变换生成目标方向；基础模型不适用时明确阻止使用其角表。偏航、预锥、预弯和变桨等可作为后续模型字段，不能预先承诺其影响都在 1°以内。

当前机械约束按设备有效读回和代码约束的交集执行：轴1±35°、轴2±180°。文档的世界仰角 40°不能代替机械限制。超界应报告哪一个方位不可达，不可把角度夹到边界后继续声称已瞄准目标。

### 4.2 方位和展向分别配置

展向测点列表与每个测点的观测方位列表分开保存。P1～Pn 的半径不同，不能复用同一组机械角度。

均匀方位按“包含起点、排除重复的 360°端点”计算：90°为 4 点，60°为 6 点。非整除步长须明确策略：优先让用户指定点数并显示实际间隔 360/N；若输入间隔，展示调整后的点数和实际间隔，不静默改变。

“叶轮前进 20°”与“转盘轴2转 20°”使用不同字段和界面名称。转盘手动微调可保留，但不作为观测方位规划按钮。

### 4.3 相位与身份

优先接入独立的每圈参考脉冲或编码器；根据实际设备条件也可评估有时间戳的独立视觉相位源。参考标记用于把叶片 A 与绝对相位绑定；B/C 的偏移须明确记录并验证。

手工 5 秒/圈仅用于角表与时序预览。没有可信相位源时可以采集原始波形或做静止测试，但不能将旋转数据标为“已确认 A 叶片”。单束激光在移动期间会失去过叶观察，不能继续靠次数 mod 3 保证身份。相位丢失、时间戳异常或身份不确定时，将相关段标为未知，重新同步后才能恢复有效归属。

测量、相位与反馈均记录本机单调时钟及数据来源时间；可用时保存设备时间和映射误差。不能以 Web 收到消息的时间控制转盘，也不能把串口反馈完成时间直接当成两轴同步采样时刻。

### 4.4 按 5 秒一圈计算时间预算

标称匀速下，同一叶片前进 Δφ 的时间为 Δφ/(6n)。以下只用于规划，在线需用相位测量更新。

| 叶轮方位间隔 | 本圈相邻到达间隔 | 额外等一整圈后的到达间隔 |
|---:|---:|---:|
| 90° | 1.250 秒 | 6.250 秒 |
| 60° | 0.833 秒 | 5.833 秒 |
| 45° | 0.625 秒 | 5.625 秒 |
| 30° | 0.417 秒 | 5.417 秒 |
| 20° | 0.278 秒 | 5.278 秒 |
| 10° | 0.139 秒 | 5.139 秒 |

三片叶片理想均布时，同一固定方位的任意叶片经过间隔约为 1.667 秒；同一片叶片回到该方位才是约 5 秒。固定观测位置的周期与移动到新观测方位的到达时间不能混用。

调度器从实际相位基准计算未来每次目标叶片到达时刻，选取最早满足以下条件的一次：

**距离预约到达的剩余时间 > 实测移动耗时上界 + 停稳确认耗时 + 数据就绪耗时 + 时钟/通信余量。**

实测上界采用测试集的最大值或经过说明的高分位值并加余量；初期可建议额外预留 20%，但硬件预检前不把 20%或固定 50 ms 当保证。已结束当前采集窗后再计算剩余时间，不能重复使用未扣除采样、防抖和处理耗时的整段时间。

计划中的跳圈正常计入总时长；非计划迟到须标记丢弃该次机会，不追赶叶片、不补造相位、不将下一片当作目标。测量期间转速变化会更新预约，已不可满足的预约取消并重排。

### 4.5 有效窗口和信号判别

宽度 w 沿实际运动方向投影、半径为 r 时，固定空间光斑的叶面经过窗口可粗估为 w/(rΩ)。但整片弦宽对应的是经过区域，不是单个材料测点允许的跟踪区域；实际值须结合光斑、材料标记、测量方向和背景。

回波判别使用真实 RSSI 采样率、设备有效性标志及连续原始样本，融合背景/叶面标定、滞回、防抖和相位预测。原始缓存保留触发前后数据，避免确认延迟把真正的进入部分丢掉。未知时间上的 RSSI 不补造样本；不能假设每个设备都以 CH1 相同频率提供 RSSI。

停止叶片、高反光背景、同一叶片表面回波起伏都必须进入验证集。2 ms 防抖、背景均值加 6σ等只能作为候选配置，不承诺能排除所有非叶片反射。可分性不足时应显示“判别不可靠”，不能继续自动换点。

## 5 软件实现结构

### 5.1 本机控制与 Web 分工

桌面采集服务负责设备控制、相位估计、轨迹/预约、信号门控、原始存储及异常停止。串口只由一个控制所有者管理，前端刷新和 Web 网络抖动不能改变运动时序。

桌面 UI 负责配置、标定、预览、运行监视与停止；Web 负责实时观察、归档、离线导入和分析，不进入毫秒级控制闭环。Web 图表可以降采样展示；原始数据保持完整并独立上传。

### 5.2 建议新增模块

| 模块 | 输入 | 输出或职责 |
|---|---|---|
| 测量对象与标定档案 | 风机/叶片/材料测点、安装尺寸、参考位 | 不可变版本的几何、坐标和点位定义 |
| 几何计算器 | 点位、叶轮方位、设备姿态 | 两轴绝对角、轨迹、可达性与误差预算 |
| 相位提供器 | 编码器/每圈脉冲/视觉或离线模拟 | RPM、展开相位、圈号、身份、时基误差、锁定状态 |
| 预约调度器 | 相位预测、目标顺序、实测延迟、采样窗口 | 预约到达、跳圈、运动截止时间和执行计划 |
| 跟踪控制器 | 同材料点的预测轨迹和反馈 | 局部执行的连续指向；超差/失锁终止有效段 |
| 有效段判定器 | 原始样本、相位、回波质量、光斑/运动状态 | 按采样索引定位的有效段、无效原因和置信状态 |
| 测量分析器 | 有效段、指标档案、校准与方向 | 速度/频带位移结果、单位、误差与适用范围 |
| 同步与分析契约 | 原始记录、事件、测点与结果 | 115 端同任务实时展示、完整归档和可重复分析 |

连续跟踪需先核对控制器是否支持足够频率的位置流、轨迹缓冲或插补。现有“定位后停稳”的接口不能通过提高 UI 刷新率变成轨迹伺服。两轴并行执行也不等于同步轨迹控制。若现硬件不能达到材料测点误差预算，应明确给出可支持的转速/短弧范围，或进入控制器/扫描光学升级评估，不降低“同点”的定义。

跟踪能力按实际两轴轨迹计算，不能只比较转盘额定转速与叶轮12 rpm。若机械角为 qᵢ(φ)，则所需轴速度为 (dqᵢ/dφ)·Ω，轴加速度为 (d²qᵢ/dφ²)·Ω² + (dqᵢ/dφ)·dΩ/dt；各项使用一致的角度单位。离线预览应显示全轨迹的速度、加速度和可达范围，现场再验证下发周期、反馈延迟、跟随误差及光斑命中。接入和退出跟踪轨迹也要满足连续性与运动限制。

### 5.3 采集生命周期与状态

同一个测量会话保持 DAQ 连续运行；移动、等待、有效测量、失锁等状态写成事件和质量段。切换点位不关闭并重新建立 DAQ，采集停止只在结束、取消或故障时执行。

驻留路径：

准备检查 → 相位锁定 → 预约目标叶片 → 运动 → 确认停稳 → 等待指定相位 → 验证进入 → 有效短段 → 确认离开 → 预约下一方位或下一圈。

跟踪路径：

准备检查 → 相位锁定 → 预测进入点 → 接入跟踪轨迹 → 验证材料测点命中 → 连续有效窗 → 退出或失锁 → 重新同步/结束。

USB断连、相位失锁、软限位、过载、原始样本缺失、失去可靠光斑命中等原因必须分别记录。停止命令发出但没有读回证实时，显示“停止未确认”；禁止自动恢复运动。网络中断只影响 Web 同步，本地任务按已验证的本机条件执行并保存，恢复后重试上传。

### 5.4 数据结构与兼容

新增结构至少包含：

- 测量档案：风机、叶片、点位、展向/弦向位置、ROI、几何和运动标定版本。
- 会话：模式、指标、原始采样率、RSSI 时序、时基、相位源、配置快照。
- 相位事件：设备/主机时间、相位、RPM、圈号、来源质量和同步不确定度。
- 运动事件：命令、目标、反馈观察区间、实际到位/停稳、超差与断连。
- 有效段：起止采样索引（结束索引不包含）、bladeId、pointId、方位、圈号、质量/无效原因；与连续原始文件关联。
- 分析结果：输入段、算法版本、单位、幅值口径、频带、方向、窗口长度和校准/不确定度。

结构化身份沿桌面→上传→Web→离线导入全链传递，不能只放入任务名称。重复上传按会话/文件标识幂等；原始块、事件文件、配置和分析结果均校验完整性。新增事件文件须同时更新桌面清单、服务器白名单、校验器和导入器。

旧记录保留旧版本读法。没有相位或材料点信息时显示“未知/历史记录”，不得自动赋予真实叶片身份。示例/模拟数据明确带来源。

### 6.3 自动结果与运行状态

以下应只读显示，不要求用户手算：两轴目标/实际角度、机械轨迹是否越限、下次目标叶片到达时间、已预约圈号/跳圈数、剩余时间预算、目标身份及相位锁定状态、光斑/有效信号质量、有效与拒收段数、窗口对应的分析能力、原始保存与上传进度。

实时图在波形上叠加进入/离开、运动/停稳、指定相位和有效段；运动或未知身份区域降低视觉强调，但原始数据保留。速度、RSSI、叶轮相位使用分离坐标与明确单位，图例和缩放轴各留空间。

多点阶段增加展向点表：点位、距叶根位置、叶长比例、弦向标记、观测方位/跟踪区间、目标段数、采集质量和结果。模板可生成 10%、30%、50%、70%、90%五点，但允许增删和修改，不将其宣称为所有叶片的最佳测点。

Web 增加“叶片—测点—圈号/方位—有效段”的筛选与追溯；实时数据和离线导入使用同一套身份/质量模型。单激光的多个测点默认逐点采集，不显示为同时测得的多点振型；跨点幅相比较必须满足参考与工况可比条件。

### 6.4 适配与设计规范

沿用现有设计 token、CustomSelect、按钮、输入、间距和状态组件。首页最多两至三列参数，小窗口按一列排列；高级参数放入独立标定页面或折叠区。名称较长的选项应有足够宽度、完整可读的选择状态和右侧图标间距。

保持原始波形/实时分析标签切换不影响采集；键盘焦点样式只在相应交互需要时出现。图表尺寸随窗口变化，控制区不覆盖坐标、图例或缩放条。Mac、Windows、Web 分别检查宽窄布局，业务界面不混入“原型验证”“未来可能”等实施文案。

## 7 分阶段实施与验收

下表中的数量、误差和比例是建议验收目标，不是已有性能。几何、频带、ROI、相位源和参考仪器确定后，形成可追溯的验收配置；不得在测试失败后默默降低阈值。

### 当前确认的首轮真实测试方式

仅使用一片明确标记的叶片A上的一个材料点P1，不增加展向测点；本轮先约定方法，后续执行时使用真实数据。

1. 叶轮停转，将A/P1摆到6点方向，瞄准并保存两轴位置、材料点位置和实际几何。保存点位不改变原有机械参考位，也不等于已经获得整段跟踪轨迹。
2. 先确认静止真实采集和沿候选短弧的几何指向。叶轮起动后等待转速稳定，转盘先保持固定观测方向，记录若干圈真实回波；结合能辨认A叶片的独立观察，估计实际周期及波动。RSSI过叶事件本身不能唯一识别A叶片。
3. 根据观测结果确定带时标的启动基准，并计算可达短弧和两轴速度/加速度需求。若只能人工同步，可安排明确标注的短时开环预测粗试，记录同步误差并独立观察光斑；不能把人工点击或启动电机时刻视为精确相位。若起始误差已大于允许光斑范围，先停在标定与同步验证步骤，不盲目执行跟随。
4. 条件满足后，“准备跟踪”提前进入就绪状态，由约定基准启动一次短弧，完成后结束跟踪。用观察记录、两轴反馈和真实波形核对光斑是否留在同一材料标记区域。没有独立命中证据时，仅能记录为轨迹运动试验。

本次粗试的目标是确认现有转盘能否执行所需轨迹并保持光斑命中；幅值准确性、连续多圈和长期自动识别仍按后续阶段验收。只靠初始位置和估计周期的预测会受起动加速、转速波动与同步误差影响。尚未接入相位反馈时，界面应显示“预测跟随/相位未锁定”，不能显示“已锁定A叶片”。现有采集按钮不自动具备上述跟踪功能，执行前需补齐对应软件路径。

### 阶段 0 离线方案与软件基础

范围：定义材料测点与配置版本，几何计算、相位模拟、预约调度、数据契约；修复三项已确认静态问题；完成页面和异常场景预览。此阶段允许在设备未连接时实施。

验收：

- 90°/60°整圈方位总数分别为4/6；起点、旋向、过360°和非整除步长均有确定结果。
- 角度与独立几何计算结果在数值精度内一致；建议纯数值误差≤10⁻⁶度，该指标不代表机械精度。
- 非法尺寸、参考失效、越限、字段混用全部被拒绝；软件不能静默夹角后把错误目标视为成功。
- 标称12 rpm、模拟变速、延迟、漏/重脉冲和断连场景可重放。预约须满足预算；计划跳圈与异常漏采有不同状态。
- 轴2独动的模拟反馈能正确更新轴2进展；不会因轴1未动而误判停滞。
- 没有身份信息的数据不会标为已确认A叶片；相位失锁后拒绝输出有效目标段。
- 页面检查1366×768、1920×1080及窄窗口；模拟和实测来源清晰，UI展示刷新不改变原始时标。

产物：版本化配置、角表/轨迹预览、状态机测试、界面预览、接口契约和验收脚本。通过仅表示软件离线逻辑通过。

### 阶段 1 重连预检与静止单点

前提：用户重新接线后确认继续测试。优先在现有同一扩展坞接法下验证；出现断连时保留日志并隔离定位原因。

范围：核实网络、串口、轴2与双轴能力、数据通道、参考位、光斑位置；选择并标记第一片叶片和一个材料测点。

建议验收：

- 连续30分钟记录设备在线与采样状态，非预期USB断连为0；若失败，不能进入自动旋转跟踪。
- 在现场允许的已确认范围内，完成各轴及双轴至少20次小角度定位/返回；无错误轴运动、无未经处理的故障、无停止未确认。具体角度/速度按现场范围确定，不由本方案直接下发。
- 保存命令发出、开始运动、到位、稳定、反馈和DAQ就绪的耗时分布。
- 几何角表在第一材料标记及若干校验位置命中；依据下文ROI预算验收，不仅看编码器角度。
- 以可追溯振动源或独立参考验证幅值。初步建议幅值误差≤5%、重复性误差≤3%；参考不确定度应明显小于允许误差，例如不超过其1/3。没有适当参考时，只能验收“取得数据”，不能签署幅值准确性。

验收配置须固定比较频带与幅值口径。幅值相对误差按 |测量值−参考值|/|参考值| 计算，参考幅值须高于约定的最小关注幅值；接近零时改用预先规定的绝对误差。重复性可按同工况至少5次独立测量的标准差/均值评价，不能用同一记录重复计算代替重复测量。上述5%与3%是建议目标，需在取得参考条件后冻结。

产物：实际几何与ROI、运动/延迟档案、采样和量纲检查、静止单点结果。至此仍未证明旋转跟踪成立。

### 阶段 2 旋转单叶片单点识别与驻留

范围：保持一个材料测点半径，先在固定可见方位识别目标叶片，再验证提前定位、到位等待和跳圈。采用约12 rpm标称工况，实际转速由可靠来源记录。

建议验收：

- 用独立相位/带时标的观察真值核对至少100圈，约8分20秒；仅按同一待验RSSI算法自证不算真值。
- 接受为目标叶片的记录错叶数为0；目标机会检出率建议≥99%。错叶率分母、有效机会数、计划跳圈数、未知身份数分别报告。
- 移动中、未停稳、身份未知、失锁和过载段不计入有效测量；这些段仍可回放。
- 比较90°和更小方位间隔的预约结果。来不及则明确跳圈，禁止把新方位的机会总按5秒预算。
- 当前材料标记实际经过时间与预计时间满足已冻结的相位误差预算；正常稳定叶片不能因RSSI转稳定而直接判为物理离开。

产物：单叶片相位识别、驻留有效短段、实测预算与丢弃原因。本阶段通过不代表已获得同一材料点连续振幅。

### 阶段 3 旋转单材料点振幅验收

范围：在已验证可见区域先做短弧同点跟踪，再根据控制能力扩展。固定使用同一叶片、同一材料标记和已冻结的振动指标。需以独立光斑观察及振动参考判断实际命中与幅值。

建议验收：

- 先连续观察至少10圈的计划跟踪区间。声明可跟踪的区间内ROI命中覆盖率建议≥99%；并且每个用于计算幅值的连续窗内部不得有未处理失锁、缺样或过载。
- 每段有效数据达到目标频带所需的长度。常规频谱初选 T有效≥max(5/f最低, 1/Δf)，最终由所用估计方法验证；不能只凭点数多认定低频可测。
- 旋转工况下与适当参考输入/同步参考比较，沿用已冻结误差要求，并报告偏差、不确定度和测量方向。静止幅值校准不能替代这一项。
- 所有移动与跟踪附加分量有可解释的处理方法；不得把未知刚体运动或平台抖动标成叶片缺陷。
- 若采用跨圈重构，需单独验证周期稳定假设、相位一致性及能恢复的频率分量，结果明确标为重构；不伪装成连续原始波形。

这是首个“旋转单叶片单材料测点振幅”交付门槛。若现转盘无法满足命中或有效时长，保留已验收驻留模式，并给出控制器/光学跟踪能力缺口；不能用降低命名标准代替验收。

### 阶段 4 同一叶片从叶根到叶尖多点

前提：阶段3的同点测量方法在首个测点通过。

范围：先增加第二个不同半径测点，再扩展自定义点表。每点重新核查几何、可见相位、光斑、有效窗、频带和投影；同一叶片身份贯穿整个任务。

验收：

- 至少三个展向位置覆盖根部附近、中部、尖部附近的可测区域；若模板选择五点，五点逐一验收，不能只验证中点。
- 每点重复至少三次独立测量会话；身份、半径、标定版本及结果不混淆。
- 根部/尖部的相位容差与窗口按实际尺度分别核算，不复用同一固定角误差。
- UI及Web逐点显示“通过/无有效窗/身份未知/未采完”，不得用其他点数据补空。
- 单束激光按点分时完成；多点幅相或振型对比需要共同参考、工况一致性和分析方法的另行验证。

### 阶段 5 桌面与 Web 完整数据验收

此阶段可从单点阶段开始并行验证，最终必须对已验收的单点及多点任务各完成一次。

- 同一真实会话在本机和115使用相同ID，Web至少观察到连续三次时间/序号递增及同一叶片测点的有效段变化。
- 正常网络下实时预览延迟初步建议95分位≤2秒，按帧采集时间到展示时间测量并说明时钟误差；这不是转盘控制精度。
- 停止后原始点数、文件SHA-256、转盘/相位事件、有效段、配置版本和分析输入一致；界面显示完整上传，不能只凭HTTP成功判通过。
- 网络断开不丢本机原始数据；恢复后幂等续传。可比较结果按相同算法版本复算一致。
- 离线导出再导入Web保留相同身份、单位、有效段和时间轴；老数据缺失字段明确未知。
- Mac与Windows分别完成软件回归。Mac实机通过不自动等于Windows设备接入通过；新Windows包在其发布任务中单独构建、安装验证和更新下载入口。

后续户外与缺陷阶段另行验收长距离光斑/回波、偏航变桨、振动方向、环境背景、健康基线与缺陷样本；模型12 rpm与现场大风机不能只按比例推定等效。

## 8 误差与分析能力的判定

### 8.1 从材料区域反推误差

定义目标ROI的实际边界，扣除光斑半径和边界余量后，得到允许光斑中心误差 B。建议将预算分配给几何/瞄准误差、相位误差和动态跟随误差，总和不超过 B；不能把每项都允许达到完整 B。

- 相位导致的位移误差近似为 r·|δφ|，其中δφ使用弧度。
- 时钟误差对应 r·Ω·|δt|；在12 rpm下，1 ms约为0.072°相位误差。
- 距离R处机械角误差ε引起的横向偏差小角度近似为R·ε。
- 建议瞄准误差95分位≤0.5B，同时所有被接受段的误差上界≤B。独立观测精度也须进入预算。

不得统一用“0.1°以内即可”验收所有半径和距离。停稳、信号有效、命中材料点是不同条件，需要分别验证。

### 8.2 频带与记录长度

12 rpm的0.2 Hz是叶轮转频，不等于叶片振动频率。每圈在同一方位仅取一个数值，采样频率只有0.2 Hz，无法直接恢复任意较高频振动。

短过叶窗口拥有很多高采样率样本，也可能缺少足够长的观察时间。升高采样率不解决低频时间窗不足。先明确最小关注振动频率与分辨率，再判断驻留、短弧跟踪、整圈跟踪或经验证的周期重构是否适用。

所有降采样前应有相应抗混叠处理，原始数据独立保留。结果显示实际有效窗、频带、幅值定义和质量；达不到条件时显示“数据不足以给出该指标”，而不是输出看似精确的数字。
