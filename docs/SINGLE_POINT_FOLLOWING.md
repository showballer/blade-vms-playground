# 单叶片单测点预测跟随

本次新增桌面端「单点跟随」入口，范围是一片指定叶片上的一个材料标记、一次短弧运动。多点功能未扩展。界面、原始记录和事件均保留“人工同步、预测跟随、命中与振幅未验证”的状态。

## 能力边界

现有转盘驱动提供从静止开始的定位，未提供可直接使用的运动中目标流或轨迹插补。本版按真实六点参考位和正对叶轮几何计算两轴短弧，用一次有界的双轴定位近似执行；不会连续发送新的定位命令来冒充伺服跟踪。

短弧最多30°，是否能够执行还取决于实际几何、运动能力和误差预算。当前模型按用户2026-10-19的新设定使用约30秒/圈（2 rpm），运行前仍需人工记录同一叶片至少5次经过。页面的运动时序初值不是设备已验证性能；不能为了解除拦截而随意放宽允许误差。

当前模型尺寸为 D=2.86 m、H=1.46 m、R=0.31 m，从激光器一侧看叶轮顺时针。新建草稿使用这组值；已有草稿保留，用户可主动点击「应用30秒模型」更新尺寸、周期、旋向与45秒同步有效期。应用模型不恢复几何/时序确认，也不更改串口、轴方向、参考位、误差容忍或设备保护配置。

相同空间轨迹由5秒降到30秒时，理想轴峰速降为1/6、峰加速度降为1/36。完整周期的俯仰峰速约0.171 rpm、水平约0.217 rpm；角度范围不变。20°短弧窗口为1.667秒，同步有效期45秒覆盖下一圈及短弧窗口，过期检查仍然生效。

按当前页面的0.6 rpm速度上限、10°/s²加速度上限及0.15秒斜坡计算，30秒/20°短弧可通过运动能力与时长预算。但定位近似误差约7.84 mm、人工/指令/轴差合计时序误差约22.72 mm，总预测约30.56 mm，仍超过2 mm路径与5 mm总误差限制。这些是模型估计，未包含新的实机标定；不能将“预览可计算”或“单轴能定位”当作同点跟随通过。

## 页面操作

1. 进入「转盘点位」完成现有参考位/软限位和手动瞄准，再进入「单点跟随」。叶轮停止，把目标叶片A的材料点P1摆到6点方向。
2. 填写材料标记、激光器至叶轮平面距离、轮毂相对出射点高度、距轮毂中心的测点半径、旋向和短弧范围。设备IP、本机网卡IP沿用采集设置；转盘串口可在高级设置刷新选择。
3. 核对两轴方向映射、已测运动斜坡/延迟、允许速度和加速度，以及材料区域允许的误差。确认静止材料点、几何与光路后，点击「准备并开始记录」。此步骤从设备读取两轴位置并冻结配置，启动真实原始采集，**不移动转盘**。
4. 使叶轮稳定转动，每次同一目标叶片的测点经过6点方向时点击一次记录。至少5次；错记、漏记或转速明显变化时清除本组并重记。系统使用服务端接收时刻估周期，人工反应与通信延迟属于误差预算，不宣称获得硬件同步。
5. 检查周期波动、同步有效期、两轴目标、短弧时长和阻止原因。全部条件通过且现场允许运动后，确认并点击「预约下一次经过并跟随」。只预约一次未来到达，不追赶迟到目标，不自动循环、不自动回位。
6. 结束后核对停止、原始记录和现场光斑观察。光斑是否始终位于同一材料标记内，需要独立观察；执行结束不代表振幅准确性通过。重新运行必须重新准备。

参数只保存为本机草稿。参考位、同步标记、任务执行权限和确认勾选不从草稿恢复。正在运行时以服务端任务状态为准，切换页面不重新创建任务。

采集服务重启会使本次参考位和同步失效，页面清除旧运行状态并要求重新准备；修改几何或运动时序后，对应的核对勾选会自动取消。迟到的旧服务响应不会恢复之前的运行状态。

## 记录与异常

准备、人工标记、重置、预约、运动命令、位置反馈和收尾均关联同一原始采集记录。记录保持连续，不在开始短弧时重新建立DAQ。配置、身份和结果摘要保存在 `manifest.json` 的 `turntable.singlePoint` 中，详细事件沿现有 `turntable.jsonl` 附件保存。

自动上传沿用现有账号绑定与持久队列，不新增远端运动控制。服务器可保留既有格式的转盘附件；本次尚未完成新的真实单点任务在115上的端到端验收。

过期同步、周期波动、参考位改变、目标越限、采集退出、时序超出预算等情况阻止启动或结束当前尝试。停止未确认时保留逐轴恢复状态；确认一轴停止不会解除另一轴的未知状态。重复命令不会重复运动，旧任务的请求不能改变新任务。停止入口可在准备请求尚未返回时使用。

## 验证方式

本次开发验证使用隔离的测试替身，测试进程不连接实物、不启动当前桌面实例。产品单点功能只使用真实采集源，不接受模拟采集请求。

- `npm run test:single-point`：页面契约、草稿权限、桌面请求校验、上传会话及取消竞态。
- 在 `services/acquisition` 下运行 `.venv/bin/python -m unittest discover -s tests -p 'test_single_point*.py'`：几何/时序预算、状态机、一次执行、原始记录和故障收尾。
- `npm run typecheck` 与桌面构建：共享类型和打包检查。
- `scripts/single-point-ui-smoke.cjs`：隔离页面交互及宽窄布局截图；依其脚本说明启动。
