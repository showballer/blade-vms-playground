# 转盘点位：自动跟随与多测点采集

自动跟随入口位于「转盘点位」，与「手动控制」共用设备。一次启动只采当前选中的一个径向测点；该测点的圆周站位完成后停止，再由用户选择下一个测点、重新瞄准并启动。采用到位后驻留采集、回波确认离开后换点的工作方式。读取控制器后自动选择双轴同时定位或旧版逐轴定位；转盘运动期间不把数据记作该点的有效测量，双轴联动也不表示已实现叶片连续光学跟踪。

本说明对应 Windows 1.5.6 测试版与共享的 Mac 页面。1.5.6将普通采集与手动定位联合采集的入口合并整理，详见下节。1.5.5新增新版控制器双轴能力探测、同时换点与运动时间反馈；明确不支持轨迹协议的旧固件继续逐轴定位。手动逐测点、同任务多测点分组及有效片段功能从1.5.4起保留；1.5.4安装包不包含新版双轴适配，1.5.3也不包含逐测点流程调整。

本地离线软件检查已通过；本次Windows CI、安装包验收以对应构建随附报告为准，本文不将其记为已完成。真实双轴联动与Windows实机尚待验证，已完成的单轴测试不替代双轴或采集联动验收。安装与重建步骤见 [Windows测试说明](../WINDOWS_TEST_GUIDE.md)，当前安装文件为 `BladeVMS-Setup-1.5.6-x64.exe`。

## 普通采集与手动联合采集

Mac 与 Windows 使用同一套入口：「数据采集」只启动固定光斑的普通采集，不包含转盘开关或运动配置。「转盘点位 → 手动控制」共用一套串口、轴、目标角度和定位转速，下面的「定位并采集」填写任务名称、设备/本机 IP 和可选停止时长后启动，无须另外点击“确认定位设置”。启动确认后，程序先重新检查并绑定转盘配置与参考，再沿用原联合采集服务：先接收测振数据，再移动所选单轴，到位后继续记录。另一轴不移动；这不是自动站位采集。

联合任务启动后跳转到实时波形页，手动模式和全局均可停止并保存。自动停止时长从开始定位后计算，0 为人工停止；时长到但尚未到位会保留异常结果。普通采集启动参数仅取任务与设备地址，不继承旧草稿中的转盘或多点指令。两轴目标与定位转速分别保留，点位回位仍使用独立的每轴速度上限。

本次仅调整界面和启动编排。原始波形、RSSI、`turntable.jsonl`、记录编号、导出及上传契约不变，不迁移或重写已有记录。现有自动站位流程仍由「自动跟随」独立启动。

## 参数与首次准备

日常填写任务名称、叶片编号、每圈时间，以及本次测点到轮毂中心的半径。列表可以保存多个测点，但每次只执行选中的一个，不会自动切换到其他径向测点。比如完成 P1 后，添加并选择 P2，填写它的实际半径，重新瞄准后再开始；P1 的记录继续保留。

安装尺寸沿用提供的实测值：D=2.86 m、轮毂中心相对激光出射点高差H=1.46 m、P1半径R=0.31 m。当前测试周期设为每圈30 s（2 rpm），从激光器面向叶轮看为顺时针。默认圆周间隔90°；此角度是叶轮平面中的圆周方位间隔，不是转盘直接转90°。

安装信息和回波判定参数放在展开设置中。安装位置改变后须重新量取与瞄准。几何计算假设叶轮平面竖直、出射点位于轮毂正前方；明显横向偏置、叶轮倾斜或轴心偏置不能据此当作已补偿。

1. 在手动控制中选实际串口、读取两轴反馈，核对参考位、故障和软限位；需要设置参考位时，按控制器要求放置真实参考姿态。
2. 停稳叶轮，将目标叶片的第一个测点放在6点方向，手动将激光对准它。
3. 切换「自动跟随」，选中本次测点，首次安装时核对尺寸与「转盘安装设置」，点击「以当前位置为起点」。系统读取真实两轴位置，检查静止、参考位和软限位。该操作只读取位置，不开始运动或采集。
4. 切换测点（即使半径相同）、安装参数或串口发生变化时重新瞄准并读取起点。软件只保留用户参数，重启后需要重新读取起点。
5. 填设备IP和本机有线网卡IP，准备好光路和运动空间后点击「开始自动采集」；系统开启激光并按路线自动换点，无须重复勾选。未连接设备时页面不生成波形或虚构角度反馈。

## 自动执行

当前测点依次访问0°、90°、180°、270°等配置站位。顺时针从6点方向依次对应9点、12点、3点。当前测点配置的站位和重复轮数完成后停止；不会自动开始列表中的下一个径向测点。

已确认支持新版双轴定时轨迹时，每次换点将两轴目标与起停轨迹一并下发，由控制器同时执行；明确返回不支持该协议的旧控制器仍先定位轴1、确认停稳后再定位轴2。未读取设备能力时页面显示“待检测”，驱动缺失或通讯失败不能当作已支持双轴，超时也不能当作旧固件兼容成功。两轴均到位后等待回波进入，持续采集，确认回波离开后冻结本站原始数据，再开始下一站运动。未观察到完整进入和离开、信号中断或设备报错时，保留相应记录并停止，不按定时器强制移动。

默认每站最多等待两个叶轮周期，即60秒。回波判定沿用每10ms窗口的P90−P10波动值：进入阈值8个百分点、持续20ms；进入后降至3个百分点以内、持续30ms判定离开。这些是可调整配置，须用现场背景和叶片信号验证，不属于自动完成的标定。

换点速度按站位之间的名义时间间隔计算，并取0.02 rpm步进，默认不超过0.6 rpm。旧控制器以两轴移动距离之和计算运动下限，未计加减速。新版双轴以较大的轴位移为基准，采用静止起步、静止到达的三次曲线，同时考虑速度和加速度上限；页面显示的是估算，服务端还会校核控制器时间/角度精度，必要时延长运动时长。两种方式都另需串口通讯与停稳确认，不能保证赶上下一次经过；速度不足时等待后续经过，不提高上限或省略停稳检查。

「俯仰轴方向 / 水平轴方向」表示光斑向上/向右时，控制器角度应增加还是减小，是设备安装标定，不是叶轮旋向，也不是运动速度。安装方向不变时无需重复填写，放在默认折叠的「转盘安装设置」中。一次起点读取只能确定当前位置，不能自动确定正方向。

「两轴换点转速上限」限制每个轴的输出轴速度，默认0.60 rpm；「自动换点速度上限（每轴）」是程序计算结果，不代表运动全程匀速。新版双轴按各轴位移分配速度，在同一时间到位；旧版按同一上限依次定位。自动换点不采用手动模式的定位转速，无需为日常采集分别填写两轴速度。运行反馈中的运动计划与实际用时来自服务端，优先于开始前的估算。

## 记录与汇总

本机记录按「采集任务 / 叶片→径向测点→独立采集批次与轮次→圆周站位」组织。同一任务下先后启动的 P1、P2 归在同一任务内，各自保留独立采集批次、站位计划和原始文件。重复采 P1 也不覆盖先前记录。原始记录保留半径、方位、目标/反馈角度、参考位签名、进入/离开事件与完整计划；波形保持各站原始时间，不拼接成虚假的连续一圈。

系统自动生成任务编号并随当前草稿保存，无需填写。保持任务名称、对象、机组和叶片编号一致时，添加/切换测点继续归入当前任务；修改这些任务信息后，下次开始会建立新的任务编号。不会仅凭同名任务合并历史数据。没有任务编号的历史记录仍按原采集批次展示。

“一圈完成”仅表示该测点配置的一组圆周站位均有有效经过记录，不保证来自同一个实际旋转周期。没有叶片身份传感器或可靠相位信号时，RSSI无法区分哪一片叶片；叶片编号为人工指定，记录始终保留身份未核实标记。不能据此直接出具某一片叶片的缺陷结论。

汇总显示已观测、异常、缺失/尚未收到记录的站位及同步状态。上传沿用现有Web绑定和自动同步，分组信息随原始记录元数据传送；未完成或异常原始文件不冒充上传成功。离线时仍可采集并保存，联网后再上传。

## Web有效片段分析

新版客户端同步与完整CSV/GZ导出保留任务、叶片、径向测点、圆周站位和回波进入/离开边界。配套新版Web按这些边界筛选有效片段，分别计算频谱和速度幅值，再比较同一圆周站位的径向点分布；不会删除间隙后冒充连续一圈。没有共同相位时不输出实测振型。客户端与此版Web需配套发布，115部署状态以发布记录为准。

## 分阶段验收

1. **软件检查**：几何与速度计算、配置透传、双轴能力探测与旧版逐轴兼容、起停速度/加速度校核、参考失效、RSSI进入离开/超时/中断、停止和多测点分组。隔离测试替身只用于开发检查，不注入用户工作台。本地离线检查已通过；Windows构建与包内验收单独记录，不据此推定本次CI已完成。
2. **单测点实机（待验）**：使用P1、30秒一圈，先验证所识别运动模式下的两轴到位停稳、回波确认后换点，核对原始样本与站位编号。真实双轴和Windows实机分别保留验收记录；任一轴状态不正常时先不开展两轴运动。
3. **多测点实机**：P1结束后添加并选择不同半径的P2，手动重新瞄准并读取起点，再独立启动。逐站核对瞄准位置、两次记录在同一任务下分点显示、缺站处理、停止后保存与Web上传。
4. **同叶片身份与定量测振**：接入身份/相位基准，验证目标叶片匹配、相位误差及测量量的校准，再评估连续跟随和缺陷判断。软件分组不替代这一步。
