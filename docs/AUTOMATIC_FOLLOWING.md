# 转盘点位：自动跟随与多测点采集

自动跟随入口位于「转盘点位」，与「手动控制」共用设备。一次启动只采当前选中的一个径向测点；该测点的圆周点位完成后停止，再由用户选择下一个测点、重新瞄准并启动。采用到位后驻留采集、回波确认离开后换点的工作方式。读取控制器后自动选择双轴同时定位或旧版逐轴定位；首次定位、点位间移动及跨轮返回期间激光保持开启，但不启用叶片进入／离开判定，也不把运动数据记作该点的有效测量。双轴联动不表示已实现叶片连续光学跟踪。

本说明对应1.5.7共享的 Mac / Windows 页面。转盘点位只负责配置和校准；普通与联动采集统一在「数据采集」启动、看波形、停止保存。Windows安装包及实机验收以各自构建和现场报告为准。

顶部账号旁的激光按钮显示当前设备回读状态，约每秒刷新；其他页面或设备上的激光开关变化也会同步。激光关闭时可点击「开启激光」并确认，开启时可直接点击「关闭激光」。连接异常或状态过期时显示未知，可点击「检查激光」重新读取，不把未知状态当作已关闭。采集期间由采集流程控制开关，顶部继续显示回读结果；需要手动控制时先停止并保存。

## 共用作业零点

在「转盘点位」左上角，将激光调为水平、正对风机旋转中心的竖直中线，两轴停稳后点击「设置归零」。软件重新读取两轴，将当前位置作为共用作业零点，显示为0° / 0°，并用作自动跟随的公共光学基准。手动目标、当前反馈、已保存点位、自动测点首个点位和路线目标均相对此零点显示；例如设备俯仰15°设为作业0°后，输入作业1°对应设备16°。点击「恢复设备坐标」只恢复显示，保留自动计算使用的公共光学基准，不移动转盘。

原点仅在本次客户端会话且串口、控制板参考、采集服务均匹配时有效；重启客户端或服务、更换串口、重设参考或停止状态未知后重新设置。本机一旦使用公共光学零点，会保留需要该基准的标记，不保存或恢复实际设备姿态；零点失效后，未校准测点须重新归零才能启动，不能静默回退到设备0°。独立测点校准仍优先于公共基准。运动与采集中不能归零。原设备参考、实际限位、已保存点位和采集上传的设备绝对角不改写；作业范围由原范围减去零点计算，不因归零扩大行程。

「回到原点」回到本次设置的两轴公共原点，沿用「自动跟随 → 转盘安装设置」当前的两轴换点转速和加速度上限；修改后无需重新归零，下次手动回位立即使用新值。按钮下方显示实际下发值；点击后直接检查并回位，无需二次确认，固定本次参数，执行中不动态改速。参数无效时禁止发送运动指令，不回退到固定低速；「恢复设备坐标」仍只切换显示，两者不混用。回位前重新读取参考位与实际限位，回位后重新读取并确认两轴停稳、误差不超过0.1°才显示完成。期间可点击「停止回原点」。原点失效时须重新归零，不把设备0°冒充原作业零点；回位不会写入厂家参考位或修改保护范围。

未校准测点按安装几何从公共光学基准计算：首点位于旋转中心正下方，水平目标等于公共零点的设备水平角，俯仰目标等于公共零点的设备俯仰角加上几何俯仰角。开始后先定位到首个点位，再等待叶片。共用归零不会将当前位置绑定成P1，也不会覆盖各测点已有的独立校准。已校准测点优先使用其瞄准姿态，首次首个点位只读核对并原地等待；位置变化超过0.1°时拒绝启动，要求重新瞄准并校准，不自动补移。共用归零也不替代厂家参考标定，不能在任意姿态执行俯仰「确认当前为+25°参考」。

## 手动点位联动采集

1. 在「转盘点位 → 手动控制」选择串口、读取两轴反馈，核对参考位、软限位和故障状态。继续使用已有点位，无须删除或重建；参考或串口不一致的历史点位需要重新标定。
2. 在「点位记录与采集路线」保存要测的位置，勾选参与采集的点位，用上移/下移确认顺序。默认所有已保存点位参与；取消勾选只排除本次路线，不删除点位。
3. 设置「点位移动速度」（每轴上限，默认0.2 rpm）、「循环次数」（默认1）和「每点最长等待」（默认60秒）。叶片进入/离开阈值放在折叠设置中，按现场回波验证。
4. 点「前往数据采集」，填写任务、设备与本机有线网卡IP，勾选「联动转盘与测振仪」，核对路线摘要并点击「开始采集」。未勾选时只做固定光斑普通采集，不读取或控制转盘。
5. 确认开始后重新读取两轴，核对整条路线的参考和限位。随后到首点停稳、等待叶片进入与离开、冻结当前点位数据，再移到下一点。严格按选定顺序执行，不做最短路径重排。循环间回到首点继续下一轮；最后一轮最后一点完成后停止，不额外回位。
6. 没有确认进入和离开、信号缺失或超时均停止并提示，不按定时器强制换点。每个点位独立保存，保留进入/离开样本边界；运动过程不计为当前点位有效测量。

配置页面不再提供「定位并采集」或独立的采集起停按钮。上方单轴目标角度只用于手动瞄准，不是点位路线启动条件。采集期间统一在数据采集页或全局「停止并保存」，可查看实时波形、实时分析和跟随进度。重开客户端不会自动勾选联动或恢复几何校准。

保存和上传沿用既有格式与队列；「本机记录 → 查看波形 / 上传至 Web」继续可用。历史记录不迁移、不覆盖。

## 参数与首次准备

「数据采集」的风机任务代表本次测量的一台风机；可额外填写风机编号和测量对象。「转盘点位 → 自动跟随」统一设置该风机的多个叶片、每个叶片的多个径向测点，以及叶轮周期、点位间隔和每点采集轮数。叶片编号在同一风机内唯一，测点名称在同一叶片内唯一；不同叶片可各有 P1、P2 等同名点。

「测量与连接设置」位于「叶片与测点」之前。叶片长度统一量取风机转轴中心到叶尖的距离，不再填写叶根偏移。每个叶片可分别设置「叶根预留 · %」「叶尖预留 · %」，默认各10%；在剩余区间内等分生成5个测点。第i点半径为 L × [根端预留/100 + (i−1) × (100−根端预留−尖端预留)/400]（i=1…5）。例如L=0.78m、两端各10%时，P1～P5为0.078、0.234、0.390、0.546、0.702m。两端比例之和须小于100%，测点半径仍需满足0.001～1000m。输入长度或比例不会覆盖当前测点，点击「生成5个测点」才应用；生成后名称与距离仍可手改。重新生成只替换当前叶片配置，已保存记录和其他叶片保留；新点不沿用旧点的光斑校准。旧配置的非零叶根偏移只在长度定义迁移时合并一次，已有测点坐标不移动。

勾选「联动转盘与测振仪」并选择「自动跟随」后，采集页按叶片列出全部测点，每行有采集状态和「开始采集」。默认按安装几何计算角度，有公共光学零点时加上其设备角度，不要求逐点光斑校准。点击开始并确认后，软件先读取两轴真实参考位，校核静止、故障、限位与运动能力；未校准测点自动定位到首个点位，已校准测点须仍位于其首个点位并原地等待。一次仅运行一个测点，完成或停止后再由用户启动下一点，不自动切换叶片或径向测点。

设备到叶轮平面的垂直距离D按实测填写。日常填写「激光出射点离地高度」，「风机旋转中心离地高度」放在折叠的「风机旋转中心高度」中，安装时设置一次、换风机或安装位置变化后更新。高差H自动取两者之差，不再手填；本次模型实测为1.50−0.65=0.85 m。旧配置尚未补充离地高度时保留并明确显示原有高差；开始输入新高度后，缺失或无效的值不会回退为旧高差。每个测点使用列表中的风机旋转中心相对半径。当前测试周期设为每圈30 s（2 rpm），从激光器面向叶轮看为顺时针。默认圆周间隔90°；此角度是叶轮平面中的圆周方位间隔，不是转盘直接转90°。

进入自动跟随页时自动枚举串口一次，只有一个可用设备时自动选择，旁边刷新图标可重新获取；此操作不读取位置、不发运动或采集指令。安装信息和回波判定参数放在展开设置中。安装位置改变后须重新量取。几何计算假设叶轮平面竖直、出射点位于风机旋转中心正前方；明显横向偏置、叶轮倾斜或轴心偏置不能据此当作已补偿。

没有公共零点时，默认设备俯仰0°为激光水平、水平0°为正对叶轮；设置公共零点后，相同光学姿态对应所读取的设备角度。两轴方向映射按实际安装填写。几何角度不替控制器建立参考位。两轴都需要真实参考有效；俯仰轴须启用有效软范围，水平轴允许明确关闭软范围，开启时须遵守实际范围。客户端仍限制俯仰±35°、水平±180°。范围未知、参考失效或任一轴异常时拒绝运动，不自动重设参考或修改保护。

1. 在「自动跟随」核对已获取的串口、实际尺寸、叶轮周期、点位间隔及轮数。几何计算基准与实际光路一致时，可直接到数据采集开始，无须每个点先校准。
2. 若发现某个点的理论瞄准位置有偏差，先停稳叶轮、把该点放在旋转中心正下方，在顶部「手动控制」调整光斑，再回到对应测点行点击「校准」。测点行已移除仅作跳转的「手动瞄准」。校准只读取两轴反馈，不运动、不识别物理测点、不开始采集；该测点全部圆周点位会叠加首个点位的统一角度修正，页面明确显示整圈修正量。「已记录首个点位」仅代表已读取姿态，不代表已验证整圈光路。此方法只适用于瞄准了正确半径的正下方测点、且几何尺寸与轴方向准确的角度零偏修正；不能用任意估计姿态标定未知几何。
3. 各测点的校准独立，同一会话内切换点位不丢失；修改该点半径只清除该点修正，公共几何、参考位、任务或服务代次变化使相关修正失效，恢复按安装参数计算。点击「恢复计算」可主动移除该点修正。重启不恢复硬件校准。
4. 准备好光路和运动空间后点「前往数据采集」，勾选转盘联动、选择自动跟随，在对应叶片/测点行点击开始并确认。未连接设备时可以查看理论角度，不能以虚构反馈绕过真实设备检查。

## 自动执行

当前测点依次访问0°、90°、180°、270°等配置点位。0°点位是旋转中心正下方的几何位置，启用可选校准时叠加该测点的实测偏角修正。当前测点配置的点位和重复轮数完成后停止；不会自动开始列表中的下一个径向测点。

已确认支持新版双轴定时轨迹时，每次换点将两轴目标与起停轨迹一并下发，由控制器同时执行；明确返回不支持该协议的旧控制器仍先定位轴1、确认停稳后再定位轴2。未读取设备能力时页面显示“待检测”，驱动缺失或通讯失败不能当作已支持双轴，超时也不能当作旧固件兼容成功。首次定位、点位间移动和跨轮回首个点位均保持激光开启。回波确认离开后先冻结当前点位有效边界、退出接收线程并停用当前点位判定器，再发送下一个点位运动；两轴实际到位、停稳且完成参考与保护复核后，才新建下一个点位记录并启用全新的RSSI进入／离开判定，前一个点位的进入状态或运动期间的回波不能触发下一次换点。激光真实开启未确认、接收线程未退出或定位未确认时停止流程，不放行下一个点位。正常完成全部配置轮次后，停止DAQ并自动回到本次任务保存的作业原点；回程不采集、不启用叶片判定，确认两轴到位停稳后才显示完成。作业零点保持不变，激光继续开启，可在顶部手动关闭。人工停止或异常时不自动回原点，尝试关闭激光并读取实际状态；关闭失败明确报错，不能宣称已关闭。未观察到完整进入和离开、信号中断或设备报错时，保留相应记录并停止，不按定时器强制移动。

「数据采集」勾选联动后显示轨迹与到位卡片：虚线为计划点位，实线来自当前页面接收到的两轴实测反馈，间断处不连线；不会按目标角度播放伪造的实际运动。卡片展示俯仰/水平当前角、目标和偏差、激光状态、圆周方位及测点距离。测点距离统一显示距风机转轴中心的距离，不再重复显示距叶根。反馈超过2秒或异常时不确认到位；切换波形/分析标签或暂停波形显示不暂停轨迹反馈。

「叶轮每圈时间」填0表示人手转动叶片。系统保持激光开启、先定位到首个点位，停稳后开启采集与叶片判定，确认叶片进入并离开后才换点；每轴换点速度使用「两轴换点转速上限」填写值（0.02～10 rpm，默认0.6），不再额外限制为0.6 rpm，不根据虚构的周期赶相位。手动转动时每个点位最多等待60秒；非零周期沿用按等待圈数计算的超时，例如30秒一圈、等待两圈就是60秒。配置的采集轮数仍表示每组圆周点位重复几轮，不表示已经验证实际风机转了相同圈数。

回波判定沿用每10ms窗口的P90−P10波动值：进入阈值8个百分点、持续20ms；进入后降至3个百分点以内、持续30ms判定离开。这些是可调整配置，须用现场背景和叶片信号验证，不属于自动完成的标定。

非零周期下，每段换点速度依据相邻点位的方位角差、叶轮每圈时间和实际两轴行程重新计算，使用半个点位时间间隔作为运动预算，并取0.02 rpm步进，默认不超过0.6 rpm。初始定位、旧路线的跨径向组定位保留已批准上限。记录的 arrivalMove.stationTiming 保留本段周期、间隔、速度预算和是否可能错过下次经过的证据。旧控制器以两轴移动距离之和计算运动下限，未计加减速。新版双轴以较大的轴位移为基准，采用静止起步、静止到达的三次曲线，同时考虑速度和加速度上限；页面显示的是估算，服务端还会校核控制器时间/角度精度，必要时延长运动时长。两种方式都另需串口通讯与停稳确认，不能保证赶上下一次经过；速度不足时等待后续经过，不提高上限或省略停稳检查。

新版双轴运行期间使用厂商双轴位置接口读取两轴采样年龄，约每秒更新，不再高频混入完整驱动器反馈和保护配置查询。过期、无效或故障反馈会停止当前流程；只有明确不支持该位置接口的旧固件可仅显示轨迹进度，不把无采样年龄的缓存状态冒充实时位置。启动前、最终到位后仍完整核对参考位、计数单位和保护配置；参考变化会保留变化前后及异常瞬间的反馈证据。异常记录与连接错误分开显示，历史异常本身不永久禁用开始；实际参考、限位、停止未确认或通信故障仍须恢复后才能开始。

「俯仰轴方向 / 水平轴方向」表示光斑向上/向右时，控制器角度应增加还是减小，是设备安装标定，不是叶轮旋向，也不是运动速度。安装方向不变时无需重复填写，放在默认折叠的「转盘安装设置」中。一次起点读取只能确定当前位置，不能自动确定正方向。

「换点加速度上限」位于同一折叠设置中，单位为输出轴 °/s²，范围0.1～120，旧配置默认3；这是轨迹参数范围，不代表机构已验证的加速度能力。修改后用于下一次任务的首次定位、点位间换点、跨轮定位和正常回原点，页面估算、服务端轨迹点校核、控制器上传约束及记录中的 accelerationLimitDegS2 均使用同一数值。运行中不能修改当前任务。旧控制器的逐轴模式仍使用驱动器自身加减速配置，不会自动写入PA40～42。短距离运动通常受加速度限制，转速上限较高也不表示能够达到该转速。

「两轴换点转速上限」限制每个轴的输出轴速度，默认0.60 rpm；「自动换点速度上限（每轴）」是程序计算结果，不代表运动全程匀速。新版双轴按各轴位移分配速度，在同一时间到位；旧版按同一上限依次定位。自动换点不采用手动模式的定位转速，无需为日常采集分别填写两轴速度。运行反馈中的运动计划与实际用时来自服务端，优先于开始前的估算。

## 记录与汇总

本机记录按「风机任务 → 叶片 → 径向测点 → 独立采集批次与轮次 → 圆周点位」组织。同一任务下先后启动的 P1、P2 归在同一任务内，各自保留独立采集批次、点位计划和原始文件。重复采 P1 也不覆盖先前记录。原始记录保留半径、方位、目标/反馈角度、参考位签名、进入/离开事件与完整计划；波形保持各点位原始时间，不拼接成虚假的连续一圈。

系统自动生成任务编号并随当前草稿保存，无需填写。保持风机任务名称、对象、风机编号和采集设备一致时，切换叶片或测点继续归入同一任务；修改风机任务归属后，下次开始建立新的任务编号。不会仅凭同名任务合并历史数据。没有任务编号的历史记录仍按原采集批次展示。

“一圈完成”仅表示该测点配置的一组圆周点位均有有效经过记录，不保证来自同一个实际旋转周期。没有叶片身份传感器或可靠相位信号时，RSSI无法区分哪一片叶片；叶片编号为人工指定，记录始终保留身份未核实标记。不能据此直接出具某一片叶片的缺陷结论。

汇总按风机与叶片分层显示已观测、异常、缺失/尚未收到记录的点位及同步状态。采集列表以最近一次实际保存的批次判断完成：必须配置的每轮、每个点位均有确认进入/离开的实测片段；新批次有缺口不能沿用旧批次的「已完成」。上传沿用现有Web绑定和自动同步，分组信息随原始记录元数据传送；未完成或异常原始文件不冒充上传成功。离线时仍可采集并保存，联网后再上传。

## Web有效片段分析

新版客户端同步与完整CSV/GZ导出保留任务、叶片、径向测点、圆周点位和回波进入/离开边界。配套新版Web按这些边界筛选有效片段，分别计算频谱和速度幅值，再比较同一圆周点位的径向点分布；不会删除间隙后冒充连续一圈。没有共同相位时不输出实测振型。客户端与此版Web需配套发布，115部署状态以发布记录为准。

## 分阶段验收

1. **软件检查**：几何与速度计算、配置透传、双轴能力探测与旧版逐轴兼容、起停速度/加速度校核、参考失效、RSSI进入离开/超时/中断、停止和多测点分组。隔离测试替身只用于开发检查，不注入用户工作台。本地离线检查已通过；Windows构建与包内验收单独记录，不据此推定本次CI已完成。
2. **单测点实机（待验）**：使用P1、30秒一圈，先验证所识别运动模式下的两轴到位停稳、回波确认后换点，核对原始样本与点位编号。真实双轴和Windows实机分别保留验收记录；任一轴状态不正常时先不开展两轴运动。
3. **多测点实机**：P1结束后添加并选择不同半径的P2，核对计算角度，必要时手动瞄准并校准，再独立启动。逐站核对瞄准位置、两次记录在同一任务下分点显示、缺站处理、停止后保存与Web上传。
4. **同叶片身份与定量测振**：接入身份/相位基准，验证目标叶片匹配、相位误差及测量量的校准，再评估连续跟随和缺陷判断。软件分组不替代这一步。

任务完成回到的是已设置的共用作业零点，不是当前测点首个点位，也不向控制板发送归零/重设参考指令。首次未设置作业零点时使用设备坐标0°/0°；该返回目标同样在启动前检查参考位、两轴范围及软限位。回程不额外生成测量记录，回程失败保留已保存数据并显示任务异常。原点保存于本机；页面刷新或服务重启后，先只读核验串口和两轴参考位，相同则继续使用保存坐标。运动中临时的停稳提示不清空原点，正常完成任务无需重复归零。真实参考或计数单位发生变化时保留旧坐标但暂停使用，需现场重新确认；手动回原点也会先读取并核验，不能把当前位置直接当零点。

## 转盘状态检查

在「转盘点位控制」标题旁点击「转盘状态」。空闲时按当前选中串口执行只读检查，分别读取两轴驱动器报警、角度参考、速度、停止标记及双轴轨迹状态。故障轨迹保留时仍可检查，不会调用停止、复位、重新设参考或运动接口；检查不能清除控制器故障。采集、定位或其他设备操作期间只显示已有反馈，重新检查按钮禁用，避免争抢串口。

弹窗注明上次完整检查时间；读取失败、服务断开、参考在查询期间改变或任何轴信息不全时不能显示检查正常。轨迹误差是控制器保存的轨迹快照，不能当作当前静止角度误差。轴故障3（反馈单位变化／计数不连续）与轨迹故障7（跟随误差超限）分别显示；两轴转速为0也不能覆盖停机待确认或无效参考。需要最新结果时点击「重新检查」。

本机最新厂商 app(2) v3.3 没有统一解决所有故障的接口：`stop_trajectory(wait=True)` 取消整组轨迹；`reset_alarm(axis)` 在故障排除后显式停止并复位当前驱动器报警；`set_current_reference(axis)` 需要人工确认真实厂家参考姿态。驱动器报警复位不等于修复反馈单位或参考失效。平台状态入口只查询，不把这些操作合并为自动恢复。
