# 转盘点位：自动跟随与多测点采集

自动跟随入口位于「转盘点位」，与「手动控制」共用设备。采用逐轴定位、驻留采集、回波确认离开后换点的工作方式。转盘运动期间不把数据记作该点的有效测量，不要求两轴联动或运动中改速。

## 参数与首次准备

日常填写任务名称、叶片编号、每圈时间，以及每个测点到轮毂中心的半径。可添加多个测点；每个测点都有自己的圆周站位和原始记录，不限制为三个测点。

安装尺寸沿用提供的实测值：D=2.86 m、轮毂中心相对激光出射点高差H=1.46 m、P1半径R=0.31 m。当前测试周期设为每圈30 s（2 rpm），从激光器面向叶轮看为顺时针。默认圆周间隔90°；此角度是叶轮平面中的圆周方位间隔，不是转盘直接转90°。

安装信息和回波判定参数放在展开设置中。安装位置改变后须重新量取与瞄准。几何计算假设叶轮平面竖直、出射点位于轮毂正前方；明显横向偏置、叶轮倾斜或轴心偏置不能据此当作已补偿。

1. 在手动控制中选实际串口、读取两轴反馈，核对参考位、故障和软限位；需要设置参考位时，按控制器要求放置真实参考姿态。
2. 停稳叶轮，将目标叶片的第一个测点放在6点方向，手动将激光对准它。
3. 切换「自动跟随」，核对尺寸、测点半径和转盘轴向映射，再读取本次瞄准参考。仅保存用户参数，软件重启不恢复旧的现场确认与瞄准锚点。
4. 安装参数、第一测点或串口发生变化时重新瞄准；其它影响任务的参数变化后重新确认计划。
5. 填设备IP和本机有线网卡IP，核对光路及运动范围后开始真实采集。未连接设备时页面不生成波形或虚构角度反馈。

## 自动执行

每个测点依次访问0°、90°、180°、270°等配置站位。顺时针从6点方向依次对应9点、12点、3点；先完成一个径向测点的站位，再处理下一个径向测点。

每次换点先定位轴1，确认到位、静止后再定位轴2。两轴均到位后等待回波进入，持续采集，确认回波离开后冻结本站原始数据，再开始下一站运动。未观察到完整进入和离开、信号中断或设备报错时，保留相应记录并停止，不按定时器强制移动。

默认每站最多等待两个叶轮周期，即60秒。回波判定沿用每10ms窗口的P90−P10波动值：进入阈值8个百分点、持续20ms；进入后降至3个百分点以内、持续30ms判定离开。这些是可调整配置，须用现场背景和叶片信号验证，不属于自动完成的标定。

换点速度按两轴移动距离之和、站位之间的名义时间间隔计算，并取控制器的0.02 rpm步进；默认不超过0.6 rpm。页面显示的最短换点用时未计加减速、串口反馈及测振服务启动时间，不能保证赶上下一次经过。速度不足时等待后续经过，不提升安全上限或省略停稳检查。

## 记录与汇总

本机记录按「任务会话→人工指定叶片→径向测点→采样圈次→圆周站位」组织。原始记录保留半径、方位、目标/反馈角度、参考位签名、进入/离开事件与完整计划；波形保持各站原始时间，不拼接成虚假的连续一圈。

“一圈完成”仅表示该测点配置的一组圆周站位均有有效经过记录，不保证来自同一个实际旋转周期。没有叶片身份传感器或可靠相位信号时，RSSI无法区分哪一片叶片；叶片编号为人工指定，记录始终保留身份未核实标记。不能据此直接出具某一片叶片的缺陷结论。

汇总显示已观测、异常、缺失/尚未收到记录的站位及同步状态。上传沿用现有Web绑定和自动同步，分组信息随原始记录元数据传送；未完成或异常原始文件不冒充上传成功。离线时仍可采集并保存，联网后再上传。

## 分阶段验收

1. **软件检查**：几何与速度计算、配置透传、逐轴指令顺序、参考失效、RSSI进入离开/超时/中断、停止和多测点分组。隔离测试替身只用于开发检查，不注入用户工作台。
2. **单测点实机**：使用P1、30秒一圈，先验证每次两轴依次停稳、回波确认后换点，核对原始样本与站位编号。
3. **多测点实机**：添加不同半径的P2，逐站核对瞄准位置、数据归属、缺站处理、停止后保存与Web上传。
4. **同叶片身份与定量测振**：接入身份/相位基准，验证目标叶片匹配、相位误差及测量量的校准，再评估连续跟随和缺陷判断。软件分组不替代这一步。
