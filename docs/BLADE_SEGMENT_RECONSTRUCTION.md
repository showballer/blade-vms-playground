# 有效片段合并与实验振型候选

## 目标与实现

对同一叶片的不同径向测点、不同圆周角度记录，复用原有确认进入/离开的边界与质量筛选。以径向测点为单位整理有效数据，保留所有来源记录和片段边界。在各连续段独立计算频谱，汇总共同频带的无符号空间响应。原始数据不改写。

Web「旋转测振 → 叶片有效片段」新增「合并片段并合成振型候选」选项。默认搜索 20–2000 Hz，可调整。结果提供合并波形、频带空间曲线和明确标记为同相假设的周期预览。Web 导出结果 JSON 及预览；全采样率合并数据通过下面的离线工具生成。

## 离线处理

需要 acquisition 的 `requirements-web.txt`，绘图另需 matplotlib。使用安装这些依赖的 Python：

```sh
python services/acquisition/tools/reconstruct_blade.py \
  '/path/to/任务数据目录' \
  --output artifacts/blade-reconstruction \
  --min-hz 20 --max-hz 2000 --detrend linear
```

输出目录必须为空并位于原任务目录以外；不覆盖既有分析。包含：

- `merged-P*.csv.gz`：每测点全采样率合并数据；保留原始速度、处理后速度、原始索引、来源记录、角度和压缩时间。文件与测点的映射见 `result.json` 的 `synthesis.mergedPoints[].mergedFile`。
- `segments.csv`：原始半开区间 `[start,end)` 与合并区间的对应关系。
- `shape-candidates.csv`：频带幅值、归一化空间曲线、实际参与角度及曲线类别。
- `result.json`：完整计算结果、来源 SHA256、边界复算证据及假设。
- `report.html` 和三个 PNG：边界、合并波形、空间响应曲线。

可逐行验证已生成的数据，输出 `verification.json`：

```sh
python services/acquisition/tools/verify_blade_reconstruction.py artifacts/blade-reconstruction
```

检查全部导出行的原始速度、去趋势速度、时间坐标、片段索引与源文件 SHA256。`scripts/test-blade-synthesis-ui.cjs` 可由 Electron 运行，以实际 `result.json` 验证测点/频带切换、同相预览滑块和多种屏幕尺寸。

离线工具保留全部完整记录，包括有效重试。重复角度的谱按实际有效时长汇总，再对不同角度等权，避免重试次数隐式改变角度权重。合并文件保留重试原段，不将不同采样率的点强制重采样。

## 时间与频谱

有效范围为 `[entryConfirmedSampleIndex+1, exitSampleIndex)`。非有限值、超量程、无效或缺失 RSSI、可选绝对 RSSI 下限会进一步切断片段。小于 64 样本的岛段剔除。原有记录数、样本数、重复身份和片段数量限制全部保留。

有效范围内另审计超过差分绝对值 P99 的 50 倍、且大于 1e-6 m/s 的单步变化，保留首八个原始索引及总数。这只是待检查突跳标记，不自动删除可能的真实事件，也不声称已排除所有回波伪迹。

`compressed_time_s` 只表示已保留片段的累计长度，不能解释为共同采集时钟。所有 FFT/Welch 和频带能量均在每个原始连续片段内计算；没有跨拼接点 FFT、补零增益或假定连续积分。

每段采用 Hann 窗 Welch PSD；每个窗口独立去线性趋势。最多 262144 点一窗、50% 重叠。无论展示预处理是否去均值，候选谱都去线性趋势。共同频率网格不细于各径向点最长真实谱窗口中的最差频率间隔；网格还受输出预算限制。仅纳入在频带下边界至少覆盖三个周期的原始窗口。

频带速度 RMS 为 `sqrt(∫PSD_v(f) df)`。频带位移 RMS 为 `sqrt(∫PSD_v(f)/(2πf)^2 df)`，不从断续速度时域积分。位移空间曲线按最大测点幅值归一化，不逐片段任意缩放。

自动候选需所有测点的汇总谱在共同频带均存在超过邻近背景三倍的局部谱峰，且各段有足够周期。只有宽带下降趋势、窗泄漏波纹或各点互不相同的频率，不判作共同候选。该阈值是探索筛选规则，不是经过标定的统计显著性检验。

未检出共同候选时，输出 `status=band_responses_only` 和 `bandResponses`：预设倍频频带的实际响应曲线。`candidates` 保持为空，不能把频带中心解释为固有频率。若三个不同半径或可用周期不足，返回 `insufficient_evidence`。

## 物理解释范围

按用户当前要求暂当作同一叶片；四个角度近似分段跟随，而非四个同时测量方向。尚未测得跨点共同相位，也未补偿角度投影和分次采集激励变化。角度最大/最小幅值比随每条曲线提供，帮助识别这些差异。

周期预览只采用同相假设；未补入实测相位，不推断节点符号，不外推未测量的叶根/叶尖。结果不能直接确认为固有振型，不能直接判损伤。要形成可比较的带符号模态，需要共同参考通道/相位及可比较工况；采样总量增加不能替代这些信息。

边界复算使用保存的检测参数和实际 RSSI 重放原检测器。复算一致只证明软件可复现，不等于实际叶缘的独立准确率验证。

## 验证

`test_blade_synthesis.py` 验证未知片段相位下已知幅值空间曲线恢复、速度到位移的频带换算、不同采样率与质量缺口的索引、原始数据不变、重试权重、短片段低频保护、互不共同的频率与宽带瞬态拒绝、旧接口兼容和参数边界。UI 测试覆盖压缩时间、探索曲线和实测相位未知的标注。

参考计算定义：SciPy 官方 `scipy.signal.welch` 文档（PSD、窗口、重叠及去趋势）。
