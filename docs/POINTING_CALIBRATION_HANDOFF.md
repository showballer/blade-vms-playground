# 点位校正与同事测试配置（2026-10-24）

这组参数来自当前设备、当前安装位置的 P1/P5 静止叶片实测。Mac 和 Windows 共用同一套计算代码。拉取代码不会复制另一台电脑保存的参数；新系数默认是 `1`，需要在客户端填写。换设备或改变安装后，应按现场重新核对尺寸和系数。

## 一、几何与系数

入口：**转盘点位 → 自动跟随／分段采集**。

| 区域 | 配置项 | 本次填写值 | 注意事项 |
| --- | --- | --- | --- |
| 测量与连接设置 | 设备至叶轮平面 | **2.50 m** | 激光出射点到叶轮平面的垂直距离，不是斜距或到塔柱的距离 |
| 测量与连接设置 | 激光出射点离地高度 | **0.77 m** | 量出射点，不是支架底部 |
| 测量与连接设置 | 风机旋转中心高度 | **1.50 m** | 两个高度以同一地面基准测量 |
| 自动计算 | 风机旋转中心与激光高差 | **0.73 m** | 1.50 − 0.77，无需另外填写 |
| 测量与连接设置 | 叶轮旋向 | **顺时针** | 从激光器看向叶轮 |
| 叶片与测点 | 叶片长度 | **0.80 m** | 此字段指旋转中心到叶尖的距离 |
| 叶片与测点 | 叶根／叶尖预留 | **20%／10%** | 生成 5 个测点 |
| 转盘安装设置 | 俯仰角校正系数 | **0.896932** | 修正俯仰目标角，P1～P5 共用 |
| 转盘安装设置 | 水平角校正系数 | **0.950153** | 修正水平目标角，P1～P5 共用 |
| 转盘安装设置 | 俯仰轴方向 | **抬高瞄准点时角度增加** | 对应本次设备方向 |
| 转盘安装设置 | 水平轴方向 | **向右瞄准时角度增加** | 对应本次设备方向 |

生成后应核对下表；修改预留比例后，不要仅看比例，确认实际测点半径也已更新。

| 测点 | 距风机旋转中心（页面单位 m） | 尺量参考 |
| --- | --- | --- |
| P1 | **0.16** | 16 cm |
| P2 | **0.30** | 30 cm |
| P3 | **0.44** | 44 cm |
| P4 | **0.58** | 58 cm |
| P5 | **0.72** | 72 cm |

两个系数只补偿指向角，不修改测点半径、作业原点或运动速度。不要为了补偿光斑偏差，再把 P1 半径改成之前量到的 0.12 m。需要测量真正的 12 cm 半径时才填写 0.12 m。

本次 P1 四个方向已做静止叶片校正；新增水平补偿后，P5 左右由约 76 cm 调整到约 72 cm，P1 左侧复核仍约 16 cm。P5 下方仍约 70 cm，较目标 72 cm 有约 2 cm 残差。P2～P4 和中间方位尚未逐一实测，尺量结果为近似值。这些结果不代表动态跟随及振幅测量已经验收，也不能单凭这组系数断定固件或减速比有误。

## 二、连接

| 项目 | 地址／端口 | 子网掩码 |
| --- | --- | --- |
| 转盘设备（转盘状态 → 转盘连接，选网口 TCP） | **192.168.10.50:5000** | 设备侧按厂家配置 |
| 电脑连接转盘的网卡 | **192.168.10.10** | **255.255.255.0** |
| 激光测振仪设备 IP | **192.168.106.90** | 设备侧按厂家配置 |
| 电脑连接激光的网卡／客户端“本机设备网卡 IP” | **192.168.106.10** | **255.255.255.0** |

两条独立设备链路的电脑网卡通常不填网关和 DNS；保留 Wi-Fi 或其他联网网卡原有配置。拔插网卡后检查地址是否保留。“本机设备网卡 IP”填写激光这一侧的地址，不要填写转盘地址或 Wi-Fi 地址。

## 三、原点与测试方式

1. 更新后先在“转盘状态”读取设备状态。若断电导致参考失效，按厂家流程机械回零、俯仰回水平 0°，并在左右方向正确时确认水平轴为 0°。
2. 激光水平且正对风机中线时设置作业归零；有效且安装未变的作业原点可继续沿用。不要把另一台电脑保存的设备角度直接当作自己的原点。“机械回零”“俯仰回水平 0°”“设置归零”含义不同。
3. 核对上述尺寸、半径和两个系数。已有单点校准会影响路线计算；本次尺寸复核使用公共作业原点计算，避免继续沿用旧的错误单点校准。
4. 先用分段采集，**每次 1 点、圆周移动间隔 90°**。选 P1，再点击“移动到预设位置”或轨迹图对应圆周点位，停稳后只转动叶轮，让静止叶片接住光斑，量相对中心的水平、竖直距离；不要量到背景墙或塔柱上。
5. 点位确认后再旋转叶轮并开始采集。分段模式每段等待人工点击开始；若改为每次 2 点，圆周间隔仍是 90°，相邻两点采集完成后自动定位到下一段等待。

| 采集／运动设置 | 本次参考值 | 说明 |
| --- | --- | --- |
| 叶轮每圈时间 | **5 s** | 按实际转速填写；手动转动叶轮时填 0 |
| 进入／离开回波波动阈值 | **8／4** | 本次环境的测试配置，换背景后需要核对实际识别效果 |
| 进入／离开确认时间 | **20／30 ms** | 保持已有配置 |
| 分段采集点位移动速度 | **5 rpm** | 用于客户端直接定位；自动跟随按编号调用控制器点位时，以该接口的控制器默认配置为准 |
| 驱动器 PA40／PA41／PA42 | **100／100／0 ms**（两轴分别设置） | 已用过的快速测试预设；先读取，再分别应用并读回，不是本次提交时的实时硬件读数 |
| 未停稳时判定叶片 | 按测试目的选择 | 本机最近保存为开启、角度窗口 ±0.5°；仅用于流程诊断。普通质量采集应关闭，保留停稳后判定 |

“填入快速预设”只是填入表单，仍需分别应用到两轴。驱动器内部定位的加减速由 PA40／PA41／PA42 控制；旧轨迹加速度字段不替代这三个值。上述几何系数不会改写任何驱动器参数。

## 四、同事更新代码

退出旧客户端，在项目根目录切到 `main` 并拉取，然后安装依赖、重新构建和启动：

```sh
git switch main
git pull --ff-only origin main
npm ci
npm run build -w @blade/desktop
npm run desktop
```

保留本机记录和账号配置，不要清空数据目录。有未提交修改时先保留自己的修改，不要强制覆盖。

**Windows 还需更新采集服务**：本次 Python 几何模型也增加了两个系数。若使用打包的 `BladeAcquisition.exe`，应先用 [采集服务构建脚本](../services/acquisition/build-windows.ps1) 在 Windows 上重建并通过 `-StageDesktop` 放入桌面资源，再构建客户端。脚本需要现有 Windows x64 SDK 及其许可证和对应源码目录。旧的已安装客户端、旧采集服务不会因 `git pull` 自动更新；本次源码提交不包含新 Windows 安装包。
