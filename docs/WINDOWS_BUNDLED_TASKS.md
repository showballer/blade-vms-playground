# Windows 1.5.10 内置任务

Windows 安装包首次启动时，将以下任务导入当前 Windows 用户自己的数据目录。登录后进入“本机记录 → 叶片采集任务”或“叶片响应分析”选择任务。

| 任务 | 叶片 | 测点 | 角度 | 记录数 |
| --- | --- | --- | --- | --- |
| 武川风场 R001 风机测量任务 | 1、2、3 | 每片 P1～P5 | 0°、90°、180°、270° | 60 |
| 武川风场 R024 风机测量任务 | 1、2、3 | 每片 P1～P5 | 0°、90°、180°、270° | 60 |
| 化德风场B071-20 | 1、2、3 | 每片 P1～P5 | 0°、90°、180°、270° | 60 |

各任务的原始波形与分段源文件随包交付；数据来源为 `data/task-catalog/20261110/manifest.json` 指定并校验 SHA-256 的版本化归档。不会从开发电脑复制账号、密码、数据库、上传队列或设备配置。

安装目录 `resources/bundled-recordings/reference-data/` 包含两份现有风场工况的 `wind-datasets.json` 及武川参考配置。工况时间和值按仓库配置保留。桌面端提供任务波形及分析，风场工况管理和健康监测仍由 Web 提供；安装桌面包不会自动修改 Web 数据库。

重复启动不会重复导入。已删除的预置记录不自动恢复；已有同编号记录保留，不覆盖用户修改。同编号冲突会提示并记录在用户数据目录 `field-data/bundled-recordings-state.json`。不同来源手动导入产生的旧记录不自动清理。

构建使用 `scripts/prepare-windows-task-data.cjs`，先从 Git 归档重建临时记录，再生成逐文件校验清单。旧版化德导出的非标准任务编号会转换为稳定的归类编号，原编号保留于元数据，波形不变。预置数据不包含分析缓存，选择叶片后按当前版本计算。

CI 必须通过多任务导入回归、打包后冻结服务读取三任务及九片叶片波形、安装登录与卸载、采集界面及设备隔离检查后才能交付。CI 无实物设备，不替代现场设备验收。
