# 服务端整改实施与验收（2026-10-27）

本轮依据《服务端整改方案》在本地实现。范围为 Web 页面、业务 API、内置 Python 分析与相关验证；未部署 115，未操作转盘和激光，未改动桌面本机原始记录，也未自动将它们上传。

## 本地使用路径

打开 http://127.0.0.1:3210/ 并登录。导航按“旋转测振 → 模态识别 → 风场数据集 → 健康监测 → 报告导出 → 二次开发”排列，系统管理在末尾。

| 步骤 | 入口 | 操作与结果 |
|---|---|---|
| 1 | 系统管理 → 测量对象与批次 | 建立风场、风机；为尚无叶片的风机生成 3 个叶片 × 5 个空点位；建立包含一台或多台风机的测量批次。空点位不会生成波形或健康结论。 |
| 2 | 桌面本机记录 / Web 旋转测振 | 将选定真实记录上传至当前 Web，或导入带时间和单位的 CSV/XLSX。桌面“有本机记录”不等于当前 Web 已收到。 |
| 3 | 旋转测振 → 测量分析与频谱 | 对未关联记录选择“关联对象”。也可在对象维护中显式导入现有记录的对象信息；信息不全的记录留待人工关联。 |
| 4 | 风场数据集 | 选择风场，上传 CSV/XLSX，映射时间、风机编号、风速、转速等列，预览后保存。时间须含时区，单位按页面提示。没有工况也可以计算波形和频谱。 |
| 5 | 旋转测振 → 测量分析与频谱 | 选择记录后执行分析；可合并同批次、同点位、同圆周角的多次完整经过（最多 16 条）。查看原始有效波形、展示平滑、Welch 频谱、特征与复核。 |
| 6 | 模态识别 | 选择风机、批次、圆周角和比较频率，生成五点频带响应分布。未测点显示缺失，同风机三叶片可比较。 |
| 7 | 健康监测 | 查看风机概要和 3×5 矩阵；默认只取每台风机最近测量批次，不将旧批次缺测点补成正常。历史对比按同测点、同圆周角显示。 |
| 8 | 报告导出 | 选择批次、可选风机，生成结果快照，导出 Word 或追溯 JSON；包含实际身份、角度、距离、工况、特征、复核与缺测项。 |

对于旧记录，只保留摘要而没有原始波形的任务仍可查看历史；新版频谱计算要求先导入真实原始文件。不会用任务摘要生成伪波形。

## 计算口径与默认参数

- 原始输入保留。采集失败、模拟或经过边界不完整的记录不进入有效经过分析。诊断记录默认排除，显式选择“纳入诊断数据分析”后可核对片段、频谱与多点响应，仍不进入健康判断或正常参考。
- 有效段按已确认进入/离开边界、无效/超量程标记及可选 RSSI 下限提取；单连续段至少 64 个样本。没有叶片边界的普通文件按有效连续记录分析，不自动宣称它是某个叶片完整一圈。
- 频谱默认窗长 0.25 s，可选 0.001–30 s；Hann 窗，50% 重叠；每窗最多 65,536 点，受最短有效连续段限制。分辨率由 `sampleRate/nperseg` 给出。频率峰候选最多 3 个。
- 多记录仅合并同批次、同风机、同叶片、同测点、同圆周角、同采样率的数据；最多 16 条、800 万原始样本、128 个有效连续段；重复源文件/原始内容拒绝。多记录各自保留原时间，禁止用一个手填时间覆盖多条来源。
- 展示平滑比例默认 5%，范围 0–20%，0 关闭。平滑后的曲线不参与 RMS、频谱或损伤判据。窗不跨越采样间断，所以不需要靠平滑“修好”拼接 FFT 伪峰。
- 工况分箱默认风速 2 m/s、转速 1 rpm；正常参考至少 3 个**不同测量批次**，由分析员复核为正常。没有参考时仍可看实际特征，但不作相对健康判断。
- 频率下降须超过 `max(2σ, 当前及参考频率分辨率, 参考均值×5%)`，同时 RMS 上升超过 25%；连续 2 个可比批次异常才显示“疑似异常，需复核”。阈值可配。
- 频谱主峰可能受转速阶次、激励或边界条件影响。默认组合规则只是待现场标定的初始判据，不保证已具有结构损伤诊断准确率。
- 全部速度以 m/s、频率以 Hz 入库。显示曲线是有界预览，原文件仍为完整追溯源。

Welch 方法依据 [SciPy 官方文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html)；响应峰与模态识别的边界参考 [ARTeMIS OMA 说明](https://svibs.com/resources/ARTeMIS_Modal_Help_v7/OMA.html)。

## 数据和权限

新增实体存入现有 MySQL `records` 表的独立类型：`measurement_objects`、`measurement_links`、`measurement_results`、`measurement_reviews`、`measurement_rules`、`measurement_modal`、`measurement_reports`、`wind_datasets`。本轮不执行删除或重建历史数据的迁移。

修改对象、归属、复核和规则需要读回的 `revision`，过期修改返回 409。原始导入文件仍按账号隔离；新增业务对象和分析快照按课题组隔离。分析及复核限分析员/管理员；操作员只能读取本人原始来源对应的结果，包含同事来源的汇总快照不向操作员开放。新一轮分析未复核为正常时，不自动继承旧轮次的参考批准。

业务 JSON 快照覆盖这些新类型；它不是完整灾备，原始波形目录、采集附件、账号与服务配置仍需独立备份。禁止把“业务备份成功”当作原始大文件已经备份。
