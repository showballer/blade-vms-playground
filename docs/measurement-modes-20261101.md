# 室内模型 / 户外测量

本地实现，处理契约 `unified-analysis-2.3.0`。Mac 和 Windows 使用相同页面与分析服务，Web 使用同一计算引擎。

## 操作入口

桌面端「记录分析 → 旋转测振 / 叶片响应分析」增加「测量模式」。

| 模式 | 默认输入 | 拼接与汇总 |
|---|---|---|
| 室内模型 | 原记录的叶片经过范围，沿用现有质量与边界规则 | 原有几何、边界、角度汇总规则不变 |
| 户外测量 | 导入文件的完整片段；真实无效区间仍分开处理 | 按文件名叶片、测点、角度分组；独立处理各角度，再生成展示接缝 |

旧任务默认室内。显式选择模式后点击「开始分析」保存模式及新结果版本，原始记录不改写；历史版本按保存的模式回放。

## 导入本次户外包

1. 点击「导入户外分段 → 选择文件夹」，选择 `1309_三叶片四角度方法复测_2026-11-01`，也支持等价 ZIP。
2. 填任务名、风场、风机、测点；本次验证使用 `wf1 / 1309 / P1`。测点距离未知可留空。
3. 核对 12 行文件映射：三片叶片，每片 0°、90°、180°、270°，点击「建立户外任务」。无法解析文件名时补填叶片和角度。
4. 选择叶片，点击「开始分析」。各片单独显示 P1 的四角度拼接、功率谱、频带响应和平均振幅；可保存版本、上传处理结果。

不同角度的相同波形分别保留。`isCopied`、演示角度、身份未验证等原始信息留在来源中，不自动删除角度槽位。同一叶片同一角度在一次导入中重复时，需勾选保留的一份；再次导入建立独立任务版本，不覆盖旧数据。

## 计算与来源

- 保留原始 CSV.GZ、原文件头、原清单及摘要。速度保留 m/s 原值，图表换算为 mm/s。全零 RSSI 不会独自使户外任务变空。
- 无几何尺寸时采用视线速度。未知距离用测点分类轴；只有一个测点时显示单柱，不生成虚构多点或三维面。
- 去趋势、滤波、窗函数沿用统一配置。相邻真实段之间生成虚线 AR 拟合接缝，不强制首尾闭合；接缝不参加振幅、FFT、PSD、RMS 统计。
- 户外振幅和频带 RMS 先分别求各角度值，再按角度算术平均。PSD 按共同窗与频率网格等权平均。室内原有频带功率汇总方式保持不变。
- 户外上传保留完整分段与原始 CSV，避免上传降采样破坏两端的逐样本一致性。各叶片结果包只依赖该叶片的来源。
- 缺少绝对采集时钟时保持未知，不以导入时间冒充采集时间。提供原连续记录采样起点时，只叠加一次 `sourceSampleStart / sampleRate`。
- 响应展示资格独立于正式健康结论；这批数据不会自动被认定为自由衰减实验、同步多通道或已验证健康数据。

## 本地验收

使用真实户外目录，在隔离目录及临时本地账号验证，不操作硬件、不上传到 115。

| 检查 | 结果 |
|---|---|

| 桌面实际界面 | 导入、筛选联动、拼接、PSD、单点振幅与频带、FFT、STFT 可用 |
| 拼接 | 每片 4 个真实段 + 3 个有限数值拟合接缝 |
| 本地 Web | 每片角度槽位完整；无需工况即可读取响应及拼接 |
| 两端一致性 | 三个叶片包合计 12 组数值数组通过复算校验，振幅相同 |
| 室内兼容 | 原 10241804 的 20 条记录完成桌面回归；P3/P4/P5 边界修复仍有效 |
