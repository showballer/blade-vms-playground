## 结果和使用入口

1. 桌面【记录分析 → 旋转测振】：选择任务/风场/风机/叶片与真实记录，点击【开始分析】。可查看原始、有效信号、背景、FFT、Welch、时频及源区间；复核后显式重算。
2. 桌面【记录分析 → 叶片响应分析】：选择任务和叶片；完整实测段按点展示。2.2.2 默认生成宽频响应预览，按最低可用采样率限制上限；关闭频带或无法分辨指定范围时仍保留波形、PSD、振幅及覆盖。
3. 【算法配置】：不滤波、线性去趋势、Hann、LOS 是默认请求。频带用途可选自动宽频预览、指定频带响应、不计算；仅指定模式显示上下限，备注可选。频带统计比较速度 RMS，不改变波形，也不构成已识别的模态频段。投影、更正和带限派生量仍使用各自的明确条件。
4. 【保存此版本】用于后续评价引用；【上传处理结果】使用新的队列。缺依赖时显示等待，先在本机记录上传并关联到同一批次/实体，再重试；原始记录已上传不等于分析结果已上传。
5. Web【旋转测振】与【模态识别 → 叶片响应分析】共用同一组件和引擎。选择【桌面已保存结果】只读取已核验版本；【同方案 Web 重算】显式新建版本。原记录对象识别和测点关联保留在【记录与归属】中。
6. Web【模态识别 → 模态参数识别】：已保存连续段的物理量、SI 单位、来源和方向自动继承，默认完整选入，不要求普通用户填写标定文字。外部 CSV/`modal-input-1` JSON 仍需说明其通道及测量来源。自由衰减或同步多通道等实验条件单独核验，不自动合并异步角度数据。

### 导出及包协议

- `导出真实处理结果`：原始来源、真实连续段及完整 NPZ，配置、质量、几何、统计来源；没有把展示接缝当实测。
- `导出带来源拼接`：明确“仅展示，含拟合”，CSV 标记各类数据和源索引。不能拿它继续 FFT 或模态估计。
- 模态导出：参数 CSV、完整证据 NPZ/JSON、真实输入 JSON、来源及方法版本。部分识别不补造振型或相位。
- `blade-analysis-package-2.2`：压缩前后均限 256 MiB；逐文件 SHA-256，禁止链接、路径越界、重复成员和过大的嵌套数组；包含该方案的原始依赖和完整真实数组。服务端重新计算及逐数组验证使用 `rtol=1e-10 / atol=1e-12`。校验和与数值一致性不是物理叶片身份认证。
- 上传副本若曾降采样，服务端由原始依赖重新运行同一抗混叠转换并与已授权副本比对；不把 50 kHz 副本当作原生 250 kHz 输入。来源、元数据或方法版本不兼容时阻断，不退回旧算法。
