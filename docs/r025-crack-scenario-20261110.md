# R025 叶片2裂纹响应情景数据

## 数据用途与组成

名称：**武川风场-R025-裂纹情景合成-第一组**。以仓库内 R024 第二组的60条健康记录作为波形母本，以两组健康记录建立的现有项目标准作为数值对照。包含3片叶片，每片P1–P5五个测点、每点0°/90°/180°/270°四角度，共60条记录。叶片1、3是健康对照的派生数据，叶片2是假设裂纹的响应情景。

全部属于合成数据，不是R025现场采集，不是独立健康/损伤验证样本。保留基线处理ID、记录ID、来源哈希、随机种子、生成器版本和变换参数。原始R024数据、健康标准、真实风场数据及既有正式评价均不改写。

## 裂纹与振动差异的物理解释

裂纹可能降低局部弯曲刚度，在质量及边界条件近似不变时，相关模态频率可能降低，可用 f∝√(k/m) 作定性说明。开闭裂纹还可能产生幅值依赖、谐波/侧带和间歇响应；影响大小取决于裂纹位置、深度、方向、激励和运行工况。

**有裂纹不等于所有频率都降低，也不等于所有测点的速度或位移都增大。** 某些裂纹在现有测量条件下可能几乎不改变可观测信号。单凭振动幅值超限不能确定裂纹类型或尺寸。

当前户外记录是短时激光视线方向速度片段，包含非结构运动和测量误差。现有标准的100–20000Hz范围内主响应峰不是经过模态识别的叶片固有频率。因此，本数据使用可控的响应波形变换表达一种异常情景，未建立有限元裂纹模型，也未拟合真实裂纹的刚度、阻尼或深度。

## 固定生成参数

假设叶片2在P3附近存在开闭裂纹；具体位置为情景设定，不是算法定位。测点半径、采样率、点数、原背景区间与质量标记延用母本。只在原分析中可用的连续段内分离线性背景并变换剩余响应；采集间断和角度间的接缝不作为真实连续信号。

| 测点 | 叶片2剩余速度增益 | 响应时间伸缩对应频率比例 | 调制深度 |
|---|---:|---:|---:|
| P1 | 1.00 | 1.00 | 0 |
| P2 | 1.12 | 0.97 | 0.03 |
| P3 | 1.60 | 0.92 | 0.16 |
| P4 | 1.75 | 0.92 | 0.13 |
| P5 | 1.85 | 0.94 | 0.10 |

- 通过围绕片段中点的插值时间伸缩变换剩余响应，不改变采样率和时长、不循环拼接端点。该比例是模型输入，不保证每条复杂短记录的FFT最大峰严格按此比例移动。
- 加入平滑幅值调制、与解析相位关联的二倍相位分量，以及P3–P5两处局部平滑振荡脉冲；它们只是非线性/间歇响应的现象模型，不是仪器过载、丢样或单样本尖峰。
- 叶片1、3剩余速度仅作±0.3%缩放及极小确定性扰动。它们与母本高度相关，不能计为新采集的独立健康样本。
- 参数在数值对照前固定；不调整健康阈值、不删除超限项，不凭阈值反推裂纹深度。
- 时间为构造的情景时钟，不能关联成R025真实同期风况；RSSI和过载列是母本质量轨迹的拷贝，不是新仪器观测。

## 文件与图表

- `R025_裂纹情景合成_桌面端导入.zip`：60个CSV.GZ分段与来源清单，可在桌面端户外分段导入功能中选择；名称、风机、测点、角度由文件头/文件名明确给出。
- `数据来源与生成参数.json`：逐条来源、生成参数及文件SHA-256。
- `健康包络数值对照.csv / .json`：按既有第二组场景阈值比较三片叶片各100项特征，包括全部有效连续段的最大速度RMS、半峰峰值、峰值因子和峭度，以及代表段请求频带内最强响应峰。频率容差沿用当前分辨率扩展规则。
- `波形频谱预览.html`：可筛选叶片，逐测点/角度对比健康母本与情景响应，包含60组波形及FFT。纵坐标是速度或FFT速度幅值，不是位移。图形作保极值降采样，计算使用完整样本。
- `analysis/blade-*.json`：系统共用信号分析管线对三片情景叶片的完整计算结果。

导入后的原始波形与叶片响应分析可用于测试图形和处理链。分段导入器保留顶层`source=simulation`与`simulation`来源信息，并保持`diagnosticOnly=true`、`validMeasurement=false`及身份未核验，避免容器格式转换丢失合成来源。

## 健康监测结论边界

数值包络对照与正式健康评价分开：叶片2的裂纹是假设真值；超限项说明情景响应可触发异常规则，不说明算法已从振动中独立识别出裂纹。叶片1、3的范围内结果同样只是派生对照。

R024标准不会直接成为R025的正式标准；本数据没有R025同期实测风况、同型机/边界条件可比性核验或现场裂纹检测报告。**不自动发布R025正式“健康/损伤”结论，不伪造人工巡检记录，不生成损伤概率或裂纹尺寸。** 未登记的合成数据继续排除在常规实测工作区之外；明确登记的情景批次可查看图表与数值对照，仍不能纳入正式健康基线或发布正式健康/损伤结论。

后续真实损伤数据应另建实测批次，关联真实风况并核验测点和几何；明确跨风机基线可比性，执行相同处理和异常筛查，再用巡检/无损检测依据确认损伤。用真实对照样本校准灵敏度和误报率，本情景不计入现场准确率。
